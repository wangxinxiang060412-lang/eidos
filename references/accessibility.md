# Accessibility & Inclusive Design (WCAG 2.2 AA+)

无障碍不是上线前顺手补的附加项，而是产品级界面的基础门槛。**当视觉极简偏好与基本可用性/无障碍发生冲突时，无障碍永远优先。**

---

## 1. WCAG 2.2 AA 硬性定量底线

| 维度 | WCAG 2.2 条款 | 硬性量化标准 | 常见违规与修复 |
|---|---|---|---|
| **正文对比度** | SC 1.4.3 (AA) | 普通文本 **≥ 4.5:1**；大号文本（≥18pt / 24px 常规，或 ≥14pt / 18.66px 粗体）**≥ 3:1** | 浅灰副标题 `#A3A3A3` 铺在白底（仅 2.5:1）→ 调深至 `#595959`（≥7:1）或 `#6B7280`（≥4.8:1） |
| **非文本与控件边界对比度** | SC 1.4.11 (AA) | 输入框边框、复选框、开关轨道、图标、图表数据块、焦点环与邻接背景 **≥ 3:1** | 输入框边框 `#E5E7EB` 在白底上仅 1.2:1 → 用可见边框（≥ `#8E95A2`）或明显灰底表面区分 |
| **最小目标尺寸** | SC 2.5.8 (AA) | Web 指针/触控最小 **24×24 CSS px**（或含周围非重叠留白 ≥24px）；**移动端强制按 44pt (iOS) / 48dp (Android)** | 小关闭图标 `16×16px` → 扩充透明 `padding` 使热区 ≥ 44px |
| **焦点不被遮挡** | SC 2.4.11 (AA) | 键盘 `Tab` 聚焦任意控件时，不能被吸顶导航、固定底栏、悬浮客服球或 Cookie 横幅完全挡住 | 给滚动容器加 `scroll-margin-top` / `scroll-padding-bottom` 匹配固定栏高度 |
| **焦点可见性** | SC 2.4.7 / 2.4.13 | 所有可交互元素保留清晰可见 `:focus-visible` 样式（≥2px 轮廓、≥3:1 对比度），**严禁全局 `outline: none` 且无替代方案** | 使用 `outline: 2px solid var(--border-focus); outline-offset: 2px` |
| **文本放大与重排** | SC 1.4.4 / 1.4.10 | 文字放大 **200%** 或视口缩至 `320px` 时无内容丢失、无重叠、无双向滚动 | 使用 `rem`/弹性布局，禁止给带文字容器写死固定 `height` |
| **不单靠颜色表达** | SC 1.4.1 | 校验错误、选中态、涨跌、图表系列、游戏敌我标识严禁只靠红/绿颜色区分 | 必配图标、文字文案、下划线、形状或纹理冗余编码 |

## 2. 语义化、读屏器与键盘导航

1. **原生语义优先**：
   - 跳转用 `<a href>`，触发动作切记用 `<button type="button">`，严禁用 `<div onClick>` 冒充按钮。
   - 正确维护页面大纲层级（`h1` → `h2` → `h3` 不跳级），配置 Landmark（`<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`）。
2. **读屏器支持（VoiceOver / TalkBack / NVDA）**：
   - 纯图标按钮必须提供准确 `aria-label` / `accessibilityLabel` / `contentDescription`（说明动作如“关闭筛选抽屉”，而非“叉号图标”）。
   - 装饰性图标与纯背景图设 `aria-hidden="true"` / `alt=""`，避免读屏器噪音。
   - 异步反馈（Toast、保存成功、表单错误、加载完成）使用 `aria-live="polite"`（紧急错误用 `assertive` / `role="alert"`）。
3. **键盘完整可达与焦点管理**：
   - Tab 顺序严格符合视觉阅读顺序（避免滥用正数 `tabindex`）。
   - 打开 Modal / Drawer / Popover 时，焦点自动进入弹层并锁定（Focus Trap），按 `Esc` 关闭，**关闭后焦点精准回到原触发按钮**。
   - 支持复合控件键盘约定：Tabs / Radio / Menu 用方向键切换，列表/命令面板支持 `↑/↓/Enter`。

## 3. 感官、运动与输入包容性

- **色盲与色弱自检**：对关键状态栏、图表与游戏血条做红绿色盲（Deuteranopia / Protanopia）灰度与对比度验证；图表配直接数据标签或不同线型/点型。
- **减少动态效果**：完整支持 `prefers-reduced-motion` / 系统减少动效开关，关掉大幅位移、视差、闪烁与自动播放轮播，保留即时可读的状态切换。
- **禁止高频闪烁**：严禁任何区域以 > 3 次/秒频率剧烈闪烁（防光敏性癫痫风险，SC 2.3.1）。
- **手柄与辅助开关设备**：游戏与电视/主机界面遵循 XAG 112/113，保证完整方向键焦点图与显眼焦点框，无只能靠鼠标悬停才能点到的死角。
