# Motion Design & Interaction Continuity

动效不是装饰品，而是解释**空间关系、层级来源、状态因果、操作反馈与系统进度**的物理语言。本规范融合 Apple WWDC *Designing Fluid Interfaces*、Material 3 Expressive 弹簧物理体系，以及开源 Skill **Stageshow**（`benjitaylor/skills`，MIT）提炼的动效连续性与构图工艺。

---

## 1. 关键边界：生产交互动效 vs 演示型动画（借鉴 Stageshow 的正确方式）

必须严格区分两类场景，**严禁把营销演示动画的慢节奏直接照搬进真实生产应用**：

| 维度 | 演示型 / 营销型 UI 动画（如 Stageshow 适用域） | 生产环境功能性交互动效（本 Skill 主战场） |
|---|---|---|
| **目标观众** | 被动观看的读者/访客，需要放慢节奏看懂故事 | 主动操作软件的真实用户，追求即时响应与效率 |
| **时长节奏** | 0.6s–1.0s 慢移动、10–16s 编排循环、有意停顿 | 直接反馈 **0–120ms**，局部态 **120–220ms**，空间转场 **220–360ms** |
| **用户干预** | 剧本单向播放 | **随时可打断、可反向重定向、绝不锁定输入** |
| **核心借鉴自 Stageshow 的可迁移工艺** | 1. **因果连续**：有来处、有去处，绝不生硬闪现/闪灭<br>2. **静框衬动**：保持外框、页头与操作锚点稳定，仅让变化内容移动<br>3. **局部更新**：按钮改文案/图标时在原控件内平滑过渡，不销毁重建<br>4. **边缘不切字**：展开/折叠高度时先淡出内容或同步遮罩，不让容器边硬切文字<br>5. **锚点不漂移**：弹层/菜单/Bottom Sheet 固定在打开锚点边，列表变高时不乱跳<br>6. **落位即静止**：过渡结束那一帧零 1px 跳变、零字形抖动、零额外余震 | 全部 6 条工艺**原样继承**到生产 UI，并将时长压缩到不拖慢操作的生产区间 |

## 2. 动效因果九问（上线前逐个转场核对）

为页面切换、卡片展开、弹窗、Bottom Sheet、菜单、列表增删设计动画前，必须明确：

1. **为什么动？**（表达空间层级、状态变化还是进度？）说不出理由就删掉。
2. **从哪来？**（Popover 从触发按钮锚点展开；Bottom Sheet 从底部边缘升起；详情页从被点击的卡片或右侧推入。）
3. **谁触发的？**（点击、拖拽、键盘快捷键还是系统异步推送？）
4. **如何展开？**（容器与内容是否协调？是否遵循“容器先出型，内容紧随显现”，避免空壳白框停顿？）
5. **稳态是什么？**（落位后完全静止，绝不持续脉动或呼吸闪烁抢注意力。）
6. **如何关闭？**（退出速度应比进入略快 **20–30%**，干脆不拖泥带水。）
7. **回到哪里？**（共享元素/卡片详情关闭时回到原列表项位置；若原项已被滚动出视口，优雅退化为温和缩退淡出，而不是强行飞出屏幕边缘。）
8. **动画期间用户能继续操作吗？**（**必须能！**禁止整个页面加透明遮罩锁死点击。）
9. **中途被打断或连点怎么办？**（从当前物理位置与速度自然反向/重定向，绝不重置到 0 帧重播。）

## 3. 生产级 Motion Design Tokens（两类职责 × 三档速度）

参考 Material 3 Expressive（Spatial vs Effects 分离）与现代 Web/原生工程标准：

### 3.1 类别分离原则
- **Spatial Motion（空间位移/尺寸/形变）**：用于面板展开、Bottom Sheet、卡片共享元素过渡、列表重排、Tab 滑动指示器。可使用温和弹簧或快出慢停曲线。
- **Effects Motion（颜色/透明度/阴影/状态）**：用于 Hover、选中底色、淡入淡出、背景遮罩。**严禁使用带回弹的弹簧**，保持干净无过冲。

### 3.2 推荐生产参数表

| Token | 典型场景 | 时长 (Web CSS) | 推荐曲线 (CSS) | 弹簧参考 (SwiftUI / Compose / Motion) |
|---|---|---|---|---|
| `motion.instant` | 按压态、复选框勾、微小图标切换 | `80–120ms` | `cubic-bezier(0.2, 0, 0, 1)` | `stiffness: 600, damping: 38`（无回弹） |
| `motion.effect.fast` | Hover 态、Tooltip、选中色切换、Toast 淡入 | `140–180ms` | `cubic-bezier(0.2, 0, 0, 1)` | `dampingRatio: 1.0, stiffness: 500` |
| `motion.effect.default` | 主题/背景色切换、模态遮罩淡入 | `200–240ms` | `cubic-bezier(0.34, 0.8, 0.34, 1)` | `dampingRatio: 1.0, stiffness: 380` |
| `motion.spatial.fast` | Popover、Dropdown、Tab 指示条、芯片展开 | `180–240ms` | `cubic-bezier(0.2, 0.9, 0.25, 1)` | `stiffness: 480, damping: 34`（极微或零过冲） |
| `motion.spatial.default` | Bottom Sheet、抽屉、侧栏、列表行折叠/展开 | `260–340ms` | `cubic-bezier(0.22, 1, 0.36, 1)` | `stiffness: 340, damping: 30` |
| `motion.spatial.exit` | 弹层/抽屉/Toast 退出关闭 | `160–220ms` | `cubic-bezier(0.4, 0, 1, 1)` | 快速收敛，**绝不回弹** |
| `motion.spatial.expressive` | 仅限游戏、消费类品牌小图标点赞/完成徽章 | `300–420ms` | `cubic-bezier(0.34, 1.35, 0.4, 1)` | `dampingRatio: 0.72, stiffness: 360`（**仅限局部小元素，严禁用于大容器与正文**） |

## 4. 关键交互工艺细则（防低级动效 Bug）

1. **只动 GPU 合成属性**：优先仅对 `transform`、`opacity`、`clip-path` 做动画；禁止直接动画 `top/left/width/height/margin` 触发高频布局回流（折叠展开请用 `grid-template-rows: 0fr → 1fr`、FLIP 技术或原生布局动画）。
2. **手势物理三要素（Apple Fluid Interfaces）**：
   - **1:1 跟手追踪**：拖拽卡片/Sheet 时元素与手指/光标保持精确抓点偏移，无过渡延迟。
   - **速度投影（Velocity Projection）**：松手时根据释放瞬间的速度投影落点——轻轻快甩即可翻页/关闭，慢拖过半才吸附。
   - **橡皮筋阻尼（Rubber Banding）**：拉到列表或滑块尽头时增加非线性阻力并平滑回弹，给出温和边界感知。
3. **实体不幽灵化**：弹窗、卡片、移动面板以位移 + 轻微缩放（如 `0.96 → 1.0`）配合快速不透明度（前 30% 时间即达不透明）入场，避免长时间半透明叠加露底（`onion skin`）。
4. **交错入场节制（Stagger）**：列表/网格首次出现时每项错开 **30–50ms**，**总交错跨度上限 ≤ 250ms**（超过 6 项后面的直接同步显现，绝不让用户傻等第 20 项一个个蹦出来）。
5. **同控件原地态变**：按钮从“保存”变“保存中…”再变“已保存”时，保持同一个按钮节点平滑过渡文字与图标并锁稳最小宽度；数字变化优先等宽字体 `tabular-nums`，仅滚动变化位。
6. **严格遵守减少动态效果（Reduced Motion）**：
   - 检测系统 `prefers-reduced-motion: reduce`（Web）、`accessibilityReduceMotion`（iOS）、`ANIMATOR_DURATION_SCALE`（Android）。
   - 开启后：**禁用所有位移、缩放、视差与旋转动画**，保留极短（≤120ms）的透明度切换或直接切至最终可读态，**绝不删掉状态反馈本身**。
7. **高频操作零拖慢铁律**：如用户连续点击切换 Tab、筛选标签、勾选列表项、输入搜索词时，**禁止用华丽长动画阻挡下一次操作**——宁可快而克制，不可慢而油腻。
