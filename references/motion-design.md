# Motion Design, Spatial Causality & Choreography

动效是解释**触发来源、空间关系、层级变化、形态过渡与操作闭环**的动态语言。本规范融合 Apple *Designing Fluid Interfaces*、Material 3 Expressive 弹簧物理体系，以及开源 Skill **Stageshow**（`benjitaylor/skills`，MIT）提炼的动效连续性与构图工艺，专为**真实生产软件**调校。

---

## 1. 铁律：空间因果与灵动响应（生产动效 vs 演示动画）

- **禁止凭空闪现或直接消失**：所有弹窗、下拉菜单、日期选择器、浮层、折叠项与页面过渡，都必须让用户看清“从哪里来、展开成什么、关闭后回哪里去”。
- **绝不套用演示型慢节奏**：Stageshow 等演示动画用 `0.8–1.0s` 慢速叙事是为了给旁观者看故事；**真实产品用户正在高频操作软件**，所有动效必须**迅速、灵动、自然、可打断**——高频微反馈 `0–160ms`，空间转场 `180–340ms`，绝不让用户等动画放完才能点下一步。
- **继承自 Stageshow 的 6 条核心生产工艺**：
  1. **静框衬动**：外框、顶栏与锚点稳定不动，只让真正变化的局部移动。
  2. **局部原地态变**：按钮改文字/图标/Loading 在原控件内平滑过渡并锁稳宽度，不销毁重建。
  3. **边缘不切字**：高度展开/折叠时协调内容透明度与遮罩，绝不让容器边硬切文字。
  4. **锚点不漂移**：弹层/菜单/筛选框打开后固定在触发锚点边，内部列表变高/变短时不乱跳。
  5. **实体不幽灵化**：卡片、Sheet 与弹窗以位移+微缩配合快速不透明入场，禁止长时间半透叠脏（`onion skin`）。
  6. **落位即静止**：结束帧零 1px 跳变、零字形抖动、零多余余震。

## 2. 每一项重要交互的 10 要素完整动效规格

设计或审查重要交互时，必须明确全部 10 项（可落盘于 [interaction-spec.md](../templates/interaction-spec.md)）：

1. **触发来源**：哪个按钮、手势、快捷键或系统事件触发？
2. **初始状态**：触发瞬间控件自身的即时按压/激活态（`0–100ms`，指针按下即响应）。
3. **动画起点与变换原点（`transform-origin`）**：锚定触发按钮边角、屏幕底边、源卡片坐标还是视口中心？
4. **动画过程（物理与轨迹）**：位移、微缩放、遮罩揭示（Clip/Mask Reveal）、形态过渡（Morphing）还是布局重排（Layout/FLIP）？
5. **动画终点**：最终位置、尺寸、背景景深（Scrim）与焦点落点。
6. **完成后的稳定状态**：完全静止可读、触发器保持 `data-open` 关联高亮。
7. **退出及取消方式**：比进入快 **20–30%**、零回弹、干脆回到来源方向（若源锚点已滚出视口，优雅退化为温和缩退淡出）。
8. **动画中断与反向操作（Interruptible & Reversible）**：播放至一半点空白处关闭、右滑返回或反向拖动时，从当前物理位置与速度自然逆转，**绝不跳回第 0 帧**。
9. **快速连续点击处理（Rapid-Click Resilience）**：1 秒内连点 5 次开关/Tab/菜单，取消旧过渡并平滑收敛到最新状态，不锁死输入、不叠出双层浮层。
10. **减少动态效果降级（`prefers-reduced-motion`）**：关闭所有位移、缩放、视差与旋转，保留 ≤120ms 清晰透明度切换或即时切态，不丢失任何状态反馈。

## 3. 17 类高频交互空间动效选型矩阵（拒绝一刀切模板）

**核心认知：并非所有弹窗都要从按钮内部缩放，也不是所有页面都适合共享元素过渡！**按空间关系、平台规范与使用频率精准选型：

| 交互组件 / 场景 | 推荐空间策略与变换原点 | 参考节奏（入 / 出） | 注意事项与禁忌 |
|---|---|---|---|
| **1. 日期选择器 / 2. 下拉菜单 / 3. Popover** | 锚定触发按钮边缘（`transform-origin: top left/right`），微缩放 `0.95→1` + 轻位移 `4–6px` + 透明度 | `180–220ms` / `130–160ms` | 触发按钮保持 `data-open` 态；筛选高度变化时锚点边绝不漂移 |
| **4. 筛选面板** | 桌面端从筛选栏下方平滑展开或右侧抽屉滑入；移动端优先 Bottom Sheet | `220–280ms` / `170–200ms` | 面板打开时内容已就位，禁止空壳白框停顿 |
| **5. 卡片展开 / 6. 图片预览（Lightbox）** | 与源图/源卡存在强几何连续性时使用 **Shared Element / FLIP 展开**，退出回原位 | `260–340ms` / `220–260ms` | 源项滚出视口时退化为就地缩退淡出；缩放不拉伸变形文字 |
| **7. 页面详情跳转** | 遵循平台原生（iOS 右推 + 跟手边缘右滑返回；Android M3 空间切换 + 预测性返回；Web 同框体局部过渡或轻量 View Transition） | `240–320ms` | 绝不在高频工具页强行给每次路由切换加 500ms 过场动画 |
| **8. Bottom Sheet** | 从屏幕底边滑入，手势 1:1 跟手拖拽 + 速度投影吸附多档高度（Detents） | `260–320ms` / `180–220ms` | 背景遮罩同步渐变；拉过顶限带克制橡皮筋阻尼 |
| **9. 模态弹窗（Dialog）** | 屏幕视觉中心（微偏上）轻缩放入场 `0.96→1` + Scrim 淡入（因无特定按钮空间归属） | `200–240ms` / `150–170ms` | 不需要硬从遥远角落按钮飞到屏幕中央 |
| **10. 上下文菜单（Context Menu）** | 从指针点击坐标或长按对象边缘展开 | `160–200ms` / `120–140ms` | 智能翻转防溢出视口边缘，同时同步翻转 `transform-origin` |
| **11. 导航 / Tab 切换** | 选中指示条（Indicator）平滑滑移（Shared Layout），内容区保持外框不动并轻量切换 | `160–220ms` | 严禁整个窗口整屏大甩动 |
| **12. 搜索展开与关闭** | 搜索图标/触发条原地形态过渡（Morphing）为完整输入框并即时聚焦，结果面板随后显现 | `200–240ms` / `160–180ms` | 输入框变形同时已可打字，绝不阻塞键盘输入 |
| **13. 列表展开与折叠** | Grid `0fr → 1fr` 或布局动画同步推开下方行，内容淡入滞后 40–60ms、淡出提前 | `220–260ms` / `180–200ms` | 绝不让容器底边硬劈文字 |
| **14. 拖拽排序** | 拾起瞬间微浮（`scale 1.02–1.03` + 阴影加深），1:1 跟手无延迟，邻居平滑让位，落位无弹跳回正 | 拾起 `120ms` / 让位 `200ms` | 拖拽中禁止给跟随坐标加 transition 导致滞后拖尾 |
| **15. 状态切换（开关 / 点赞 / 复选）** | 开关滑块弹簧跟手；状态文字在原槽位平滑替换；极小成功/点赞图标允许局部轻微过冲 | `100–180ms` | 大容器与正文严禁弹性过冲 |
| **16. 手势返回（Swipe / Predictive Back）** | 100% 手势驱动进度，释放按速度投影决定完成返回或回弹取消 | 实时 1:1 + 释放 `220–280ms` | 与左上角点击返回视觉方向严格一致 |
| **17. 游戏菜单与 HUD 状态变化** | 受击/低血量/CD 完毕瞬时高亮响应（`60–140ms`）；菜单切换贴合世界观材质但绝不拖慢操作 | 战斗 `60–150ms` / 菜单 `160–240ms` | 高压战斗提示绝不靠慢动画延迟信息到达 |

## 4. 生产级 Motion Tokens（Spatial 与 Effects 严格分离）

禁止全项目所有动画套用同一个时长与曲线！根据运动职责选型（可在特殊交互按需微调）：

| Token | 职责类别 | 时长 (Web) | 曲线 (CSS) | 原生弹簧参考 |
|---|---|---|---|---|
| `motion.instant` | 按压态、勾选、焦点切换 | `80–120ms` | `cubic-bezier(0.2, 0, 0, 1)` | `stiffness: 600, damping: 38` |
| `motion.effect.fast` | Hover、Tooltip、选中色、淡入淡出 | `140–180ms` | `cubic-bezier(0.2, 0, 0, 1)` | 临界阻尼 `dampingRatio: 1.0` |
| `motion.effect.default` | 主题过渡、遮罩淡入、跨色相变化 | `200–240ms` | `cubic-bezier(0.34, 0.8, 0.34, 1)` | 临界阻尼 `dampingRatio: 1.0` |
| `motion.spatial.fast` | 菜单、日期选择器、Popover、Tab 指示条 | `180–220ms` | `cubic-bezier(0.2, 0.9, 0.25, 1)` | `stiffness: 480, damping: 34` |
| `motion.spatial.default` | Sheet、抽屉、卡片/列表空间展开 | `240–320ms` | `cubic-bezier(0.22, 1, 0.36, 1)` | `stiffness: 340, damping: 30` |
| `motion.spatial.exit` | 任意弹层、抽屉、Toast 关闭收起 | `140–200ms` | `cubic-bezier(0.4, 0, 1, 1)` | 快速收敛，**零回弹** |
| `motion.spatial.expressive` | 仅限小点赞/完成徽章、消费/游戏局部重音 | `280–380ms` | `cubic-bezier(0.34, 1.32, 0.4, 1)` | `dampingRatio: 0.74, stiffness: 380` |

**编排与性能红线**：
- **分阶段交错（Stagger）**：相关元素按阅读顺序错开 `30–50ms`，**总跨度上限 ≤ 220ms**（超过 5–6 项后的条目同步出现）。
- **只动合成属性**：优先仅动画 `transform`、`opacity`、`clip-path`；布局高度变化用 Grid Row 或 FLIP，避免逐帧回流掉帧与滥用全局 `will-change`。
