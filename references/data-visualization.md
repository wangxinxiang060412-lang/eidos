# Data Presentation & Visual Analytics Aesthetics

看到数据就默认画 4 张 KPI 卡片 + 1 张五颜六色圆环图，是最典型的 AI 偷懒套路。**优秀的数据展示优先服务于理解、比较与决策，其次才是视觉美感——绝不允许为了好看扭曲数据比例或制造误导。**

---

## 1. 先分析数据再选形式（9 问决策法）

动手设计任何数据模块前，必须明确回答：
1. **用户此刻最想知道什么？**（当前值？是否达标？环比变好了吗？哪一项出异常了？）
2. **数据量与维度**：1 个关键指标、5 项对比、30 天时序还是 5,000 行多维明细？
3. **更新频率**：静态月报、分钟级经营看板还是秒级实时监控？
4. **比较需求**：同类横向对比、时间纵向趋势、占比构成还是分布相关性？
5. **历史上下文**：孤立的一个“12,480”毫无意义——需要配基准线、目标线或同比/环比周期（如“较上月 +8.4%”）。
6. **主次权重**：哪 1–2 个核心指标应该成为视觉重心？哪些次级辅助数据应该降权退后？
7. **排版质感**：如何用字号反差、等宽数字（`tabular-nums`）、单位弱化与留白提升高级感？
8. **语义色彩**：哪些颜色代表真实趋势/阈值（正常/预警/异常），如何避免纯装饰彩虹色干扰判断？
9. **极简替代测试**：去掉花哨图表，仅靠 **1 个精排大数字 + 1 条极简 Sparkline + 清晰时间范围** 是否更直观、更高级？

## 2. 17 种数据展示形式精准选型表

| 数据目标与结构 | 最佳展示形式 | 适用场景与设计要点 | 常见误用（拦截） |
|---|---|---|---|
| **单一核心结果** | **大字号关键数字（Hero Stat）** | 余额、总营收、当前进度；主数值大字重 + `tabular-nums`，单位/币种缩小弱化，配对比基准 | 给 1 个数字硬套大卡片加渐变图标 |
| **3–5 项关联指标** | **紧凑数字组合（Metric Strip）** | 共享同一水平条或细线分隔的紧凑排版，扫视效率远高于独立厚卡片 | 4 张结构完全一样、重复画边框的 KPI 卡片墙 |
| **高频扫描明细** | **结构化数据列表（Data List）** | 交易流水、日志、移动端明细；数值右对齐，主次两行清晰 | 移动端强行塞 9 列横向滚不动的大表格 |
| **多维精确核对/排序** | **数据表格（Data Table）** | B 端订单、财务对账、性能指标；文字左对齐、数字右对齐、表头吸顶、支持排序筛选 | 所有列居中对齐导致数字小数点参差不齐 |
| **连续时间变化** | **趋势折线图（Line Chart）** | 流量、股价、留存趋势；突出主线、弱化网格线、直接标注关键拐点或期末值 | 超过 5 条彩色折线拧成意大利面 |
| **离散分类对比** | **柱状图 / 条形图（Bar Chart）** | 渠道排名、分月对比；分类名较长时优先**水平条形图**便于顺向阅读，**Y 轴必须从 0 起步** | 截断 Y 轴夸大微小差异；倾斜 45° 难读横轴标签 |
| **累计总量趋势** | **面积图（Area Chart）** | 强调随时间累积的体量感；填充用极轻单色渐隐，顶边折线清晰 | 多系列堆叠面积图导致中间层变化无法比较 |
| **数值区间分布** | **分布图 / 直方图 / 箱线图** | 耗时延迟 P50/P95/P99、成绩/薪资分布；揭示长尾而非只用平均值掩盖真相 | 用简单均值隐藏严重极端延迟 |
| **双维度密度/周期** | **热力图（Heatmap）** | 活跃时段（星期×小时）、打卡矩阵、关联矩阵；使用感知均匀的单色或双极色阶 | 用红黄绿彩虹色阶导致色盲无法读数 |
| **两变量相关性** | **散点图 / 气泡图（Scatter）** | 转化率 vs 客单价、异常离群点发现；加辅助趋势线或象限参考线 | 气泡用半径而非面积映射数值导致视觉误导 |
| **事件进程/日志** | **时间轴（Timeline）** | 订单流转、版本发布、故障复盘；精确时间 + 清晰状态节点 | 用复杂甘特图表达简单 4 步流水 |
| **按日日程/习惯** | **日历视图（Calendar / Contribution Grid）** | 习惯打卡、排班、账单日历；连续日期区间柔和连贯，起止日清晰锚定 | 用长列表展示强日期依赖的排期 |
| **目标达成率** | **简洁进度条 / 目标标尺（Bullet / Progress）** | 预算消耗、任务完成、配额余量；水平直条比环形图更易精确比较比例 | 满屏画 6 个占空间又难比较的粗圆环图 |
| **空间地域差异** | **地理可视化（Choropleth / Point Map）** | 门店覆盖、区域物流、用户地域；若仅看省份排名，水平条形图往往比地图更准确 | 为了炫酷画 3D 地球仪展示 5 个城市销量 |
| **依赖与流向** | **关系图 / 桑基图（Network / Sankey）** | 转化漏斗分流、资金流向、微服务拓扑；限制同屏节点数并支持聚焦高亮单条链路 | 200 个节点糊成毛线球 |
| **行内趋势上下文** | **微型趋势图（Sparklines）** | 嵌入表格或指标旁呈现 7–30 天走势，无坐标轴噪音，与数字同高呼吸 | 把完整带图例的笨重图表缩进 80px 单元格 |
| **领域专属洞察** | **定制化数据可视化** | 音频波形、心率区间、K 线深度图、技能雷达（限 ≤6 维） | 无必要强行自造用户看不懂的怪异图表 |

## 3. 数据美学与诚实度硬性底线

1. **绝不数据造假与视觉欺骗**：
   - 柱状图与面积图基线从 **0** 开始；折线图若为观察微小波动截断 Y 轴，必须清晰标明刻度范围。
   - 严禁 3D 饼图/3D 柱状图（透视变形严重扭曲比例）；占比项超 5 项时放弃饼图改用排序条形图。
2. **最大化数据墨水比（Data-Ink Ratio）**：
   - 去掉粗重外框、深色网格线、多余背景条纹与冗余图例；网格线压淡至 `rgba(..., 0.06–0.08)`，能直接把标签标在线条末尾或柱顶就不用让用户眼球在图例和图形间反复横跳。
3. **数据排版工艺**：
   - 所有数值强制 `font-variant-numeric: tabular-nums`；精确统一小数位数与千分位格式（如 `12,480.50`）；大数合理简写（`12.4万` / `1.2M`）并在悬停/详情给出完整精确值。
   - 趋势变化同时使用 **符号（`+`/`-` 或 `↑`/`↓`）+ 颜色 + 基准周期说明**，遵循目标地区红绿习惯并保证色盲可读。
4. **交互与空/异常数据完整**：
   - Hover / 点击图表点时展示精确对齐的 Tooltip 与垂直准线；空数据/数据加载中/部分缺失断点（Gap）明确区别于“真实数值为 0”。
