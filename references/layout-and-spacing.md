# Layout, Spacing & Optical Alignment

秩序感来自**克制的留白节奏、清晰的对齐轴线、精确的同心几何**——而不是把屏幕的每一寸空白都塞满，也不是为了追求僵硬数值忽略人眼的光学感受。

---

## 1. 弹性间距体系（4pt 基础节奏，按密度适配）

采用 `4px / 4pt / 4dp` 作为微调节奏、`8px` 作为主结构节奏（专业高密度桌面工具可微调使用 `2px / 6px`）：

| Token | 数值 | 典型用途 |
|---|---|---|
| `space-1` | `4px` | 标题与副标题/图标与文字的紧耦合间距、微标签内边距 |
| `space-2` | `8px` | 同组控件之间（如按钮组、图标与标签、输入框与校验提示） |
| `space-3` | `12px` | 紧凑列表行内边距、小卡片内部边距、控件距上方字段的距离 |
| `space-4` | `16px` | **移动端标准页面左右边距**、常规卡片内边距、同组列表项间距 |
| `space-5` | `20px` | 舒适型卡片内边距、弹窗内边距、平板小边距 |
| `space-6` | `24px` | 桌面页面常规边距、内容分组间距、模块间呼吸距离 |
| `space-8` | `32px` | 主区块间隔、独立功能域分隔 |
| `space-12` | `48px` | 大章节间隔、营销页/长文档区块分隔 |

### 留白分组不等式（防结构失焦）
必须严格保持：
$$\text{元素内间距} < \text{同组项间距} < \text{分组间距} < \text{区块间距}$$
例：标题与副标题间距 `4px` < 列表内相邻两行 `12px` < 两个分组之间 `24px` < 顶部总览与下方主内容区 `32px`。**只要标题到上面区块的距离 ≤ 到下面内容的距离，层级就一定错乱。**

## 2. 同心圆角公式（Concentric Radius Law）

当一个圆角元素嵌套在另一个圆角容器内时（如卡片里的图片/按钮、输入框里的胶囊标签、弹窗里的内嵌面板），**严禁内外使用相同圆角**——视觉上会在拐角处产生难看的厚薄不均。

精确计算公式：
$$R_{\text{outer}} = R_{\text{inner}} + \text{padding}$$
（或反推：$R_{\text{inner}} = \max(4\text{px}, R_{\text{outer}} - \text{padding})$）

示例：
- 外卡片 `radius = 16px`，内边距 `padding = 8px` → 内嵌封面图或内部按钮使用 `radius = 8px`。
- 外卡片 `radius = 12px`，内边距 `padding = 12px` → 内嵌元素取安全下限 `radius = 6px` 或 `4px`。

## 3. 光学对齐与几何洁癖（提炼自 Stageshow Craft）

数值对齐 ≠ 视觉对齐。以下 8 条细则能立即拉开专业设计与普通模板的差距：

1. **零近切边法则（No Near-Tangents）**：两个边界（如文字与边框、按钮与分割线、两个相邻组件）距离 **1–3px** 看起来像代码写歪了——要么**精确贴齐（0px）**，要么拉开到 **≥ 8px** 的明确呼吸距离。
2. **四周均衡留白**：卡片、弹层与弹窗的上下左右内边距必须视觉平衡；底部主操作按钮离底边不能比左右边距窄一截（防止“头松脚挤”）。
3. **文字离边缘底线**：可交互容器、卡片、弹窗或悬浮列表行内的文字距离容器边界至少 **12px**（极紧凑徽标至少 **8px**）；禁止文字紧贴边线。
4. **阅读轴线对齐（Reading Edge Alignment）**：
   - 头像 + 用户名 + 正文评论的结构中，下方正文应与**用户名左边缘对齐**（或清晰独立通栏），不要歪在头像中间。
   - 列表行内若部分项有图标/状态圆点、部分项没有，保持**固定列轨道**（Grid Track）让主文字垂直一条直线对齐。
5. **不对称图形光学居中**：三角形播放图标向右视觉偏移约 **1/6 宽度**；左/右箭头、圆角矩形旁的圆形徽章需按视觉重心校准，而非盲信几何中心。
6. **固定图标盒防挤压**：Flex 行中的图标、头像、角标必须设置 `flex-shrink: 0`（`flex: none`），防止长标题把圆形头像挤成椭圆。
7. **滚动画布与固定栏边界清晰**：顶部导航栏、底部操作条与滚动内容交界处，在内容滚动至其下方时呈现清晰 1px 分割线、轻阴影或渐变遮罩，避免滚动文字直接撞穿工具栏按钮。
8. **内容变动零布局抖动（Layout Stability）**：图片与异步区块必须预声明 `aspect-ratio` 或骨架高度；状态文字、筛选结果数变化时保持主容器与操作条位置纹丝不动（CLS ≤ 0.1）。

## 4. 网格与列数参考

| 视口宽度 | 推荐网格列数 | 左右安全边距 | 列间距 (Gutter) | 内容最大阅读/工作区宽 |
|---|---|---|---|---|
| 手机 (`< 600px`) | `4` 列 | `16px` | `12–16px` | `100%` |
| 平板 (`600–1023px`) | `8` 列 | `24px` | `16–20px` | 按模块双栏重排 |
| 桌面 (`1024–1439px`) | `12` 列 | `24–32px` | `20–24px` | 工作台流体 / 阅读与表单 `1120–1280px` 居中 |
| 超宽屏 (`≥ 1440px`) | `12` 列 | 自动留白或分栏 | `24px` | 内容容器上限 `1280–1440px`（画布/专业工具除外） |
