# Iconography & Visual Semantics

图标是高效的视觉路标，不是填补空白的贴纸。糟糕的图标系统（风格混杂、外包廉价彩色圆底、语义隐晦、重心歪斜）是 AI 生成界面最容易露馅的破绽之一。

---

## 1. 图标 10 项强制审查规范

每一个准备放入界面的图标，逐一过这 10 关：

1. **必要性测试（先问要不要用）**：去掉这个图标后，用户理解和找到该功能的速度会变慢吗？如果不会，**直接删除**（严禁给每段普通说明、每个表单标题、每个普通列表项机械前置装饰图标）。
2. **语义准确性**：图标是否直指实际功能，而非牵强比喻？（例：导出用导出箭头，不用火箭；AI 能力展示具体动词如“总结/生成/校对”，不用泛滥的 ✨ 魔法棒。）
3. **成熟心智惯例**：返回、搜索、关闭、分享、设置、删除、收藏、刷新、更多（`…`）等通用高频动作，**优先使用用户已形成肌肉记忆的标准符号**，绝不为标新立异造谜语。
4. **小尺寸辨识度**：在 `14px / 16px` 实际渲染尺寸下，线条是否清晰、轮廓是否可辨，不糊成一团？**`≤ 14px` 微型图标优先采用实心（Filled）风格**，细线框在低密屏或小尺寸下会发虚。
5. **家族与美术风格统一**：全产品锁定 **1 套主图标体系**——线框/实心规则一致、几何气质（硬朗直角 vs 温润圆角）与产品字体及圆角语言匹配。
6. **线宽统一（Stroke Consistency）**：同尺寸区域内所有线性图标使用相同视觉线宽（常见 `1.5px` 或 `1.75px`；避免因不同 `viewBox` 缩放导致有的图标线宽 `1.1px`、旁边图标 `2.2px`）。
7. **端帽与转角统一**：`stroke-linecap` 与 `stroke-linejoin`（如全员 `round` 或全员 `square/miter`）保持一致，严禁圆头和尖角混搭。
8. **填充与状态语法统一**：不在同一导航栏或工具栏里随意混排实心与线框图标；**唯一合理混用**：用“未选中线框 → 选中实心”表达明确的激活态。
9. **尺寸与光学比例协调**：
   - 同组图标即使 `viewBox` 相同（如 `24×24`），正方形/实心满格图形视觉上比三角形/斜线大 20%，需按**光学边界框（Keylines）**微调。
   - **重心校准**：播放三角形右移约 `1/6` 宽度；居中于圆形/方形按钮内的图标按视觉重心而非外接矩形居中。
   - **图文比例**：与正文 `14–15px` 并排的常规图标取 `16–18px`（绝不过大喧宾夺主）；图标与文字间距 `6–8px`，且与文字首行光学居中对齐。
10. **无障碍与标签配对**：非绝对通用图标必须配简短文字标签（或桌面端 Tooltip）；纯图标按钮必填动作型 `aria-label`；纯装饰图标设 `aria-hidden="true"`。

## 2. 禁止的 AI 图标模板病

- **彩色圆底/圆角方底盒泛滥**：把每个普通列表项或卡片标题前的图标都套进一个浅蓝/浅紫/浅绿圆角方块里——除非它承担真实的应用头像、文件类型标识或高区分度一级分类职责，否则去掉底盒，直接用克制单色图标或纯排版层级。
- **Emoji 冒充 UI 图标**：严禁用 🔥🚀💡📊⚙️ 充当导航栏、按钮或设置项图标（Emoji 仅限用户内容、消息反应或明确以 Emoji 为核心语义的笔记标签）。
- **手写粗糙内联 SVG**：避免模型凭空手写不对齐、线宽错乱的简易 `<path>` 冒充通用图标；通用语义优先选用成熟原生/矢量图标库。
- **机械依赖同一套通用库决定全产品气质**：不要对所有产品无脑千篇一律导入默认 Lucide 细线框。按平台与产品气质选型：
  - **Apple 生态（iOS/iPadOS/macOS）**：首选 **SF Symbols**（自动匹配字重与动态字号）。
  - **Android / M3**：首选 **Material Symbols**（可控 Weight / Grade / Optical Size）。
  - **Web / 跨端 / 专业工具**：按气质在 **Phosphor / Tabler / Heroicons / Radix Icons / Lucide / Iconoir** 中择一锁定，不跨库混拼。
  - **强品牌辨识度模块 / 游戏 UI**：对核心品牌特征、专属玩法技能、独特空态图形，**鼓励设计统一网格与线宽的原创定制矢量资产（SVG / 矢量路径）**，但核心通用导航仍保持一眼可懂。
- **图标防挤压与对齐**：Flex 容器中的图标必须加 `flex-shrink: 0`；使用偶数像素盒配偶数像素视图（如 `16×16` / `20×20`）避免半像素模糊与动画落位抖动。
