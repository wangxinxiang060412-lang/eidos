# Navigation Surfaces, Page Boundaries & Spatial Continuity

AI 生成界面最常见却最容易被忽略的破绽在于**页面上下边界**：顶部导航、中间滚动内容、底部栏与系统安全区看起来像三块硬拼在一起的陌生积木，要么生硬断层，要么互相遮挡。

---

## 1. 十大关键边界检查项

设计和审查每个页面时，必须逐一核查以下 10 处空间衔接关系：

1. **状态栏 ↔ 页面顶部**：状态栏图标/文字极性（深色/浅色）是否与顶部真实背景保持高对比？背景色或头图是否正确延伸至状态栏背后（Edge-to-Edge），无多余白条或黑带？
2. **顶部导航栏 ↔ 内容区**：初始静止态与页面向下滚动后，导航栏与下方内容是否自然衔接或清晰过渡？页面首个标题与导航栏下沿间距是否充足（至少等于页面左右安全边距）？
3. **底部导航栏 ↔ 滚动内容**：列表滚到最底部时，最后一条内容是否完整露出在底栏上方（通过足够的底部 `padding-bottom` 预留），**绝不被底栏或悬浮按钮挡死**？
4. **页面背景 ↔ 系统安全区**：底部手势指示条（Home Indicator）与顶部灵动岛/刘海/小程序胶囊区域，背景表面是否自然贯通到物理屏边缘，而可交互内容严格缩在 Safe Area 内？
5. **内容滚动时的导航联动**：大标题（Large Title）滚动收起、搜索栏折叠、吸顶筛选条贴顶时，过渡是否连续平滑、无 1px 闪烁或跳动？
6. **固定组件 ↔ 滚动组件**：吸顶表头、固定筛选栏、悬浮操作按钮（FAB）在内容从其下方穿过时，层次是否清楚，文字不会与下方滚动文字糊成一团？
7. **底部操作条 ↔ 表单/详情内容**：结算栏、提交栏、评论输入框与上方内容区的视觉归属是否清晰？内容不足一屏时，底部操作条位置是否稳定自然？
8. **软件键盘弹出时的边界变化**：键盘升起时，固定底栏与主提交按钮是否平滑跟随上移或合理收起？当前聚焦的输入框是否自动滚入可视区，不被顶栏或键盘夹死？
9. **横屏 / 分屏 / 桌面缩放边界**：横屏后左右安全区是否避让挖孔/摄像头？窗口变矮时弹窗内部能否独立滚动、头部和底部确认按钮保持固定可见？
10. **弹窗 / Bottom Sheet / 浮层 ↔ 底层页面**：弹层打开时是否通过克制的背景压暗遮罩（Scrim，如 `rgba(0,0,0,0.32–0.48)`）或轻微底层退后建立明确景深？底层页面滚动是否被锁定（`overscroll-behavior: contain`）防止滚穿？

## 2. 八种边界处理策略选型矩阵（禁止全员一刀切）

**核心原则：绝不默认所有边界都要加毛玻璃模糊、渐变羽化或粗分割线！**根据产品定位与信息结构选择最恰当的衔接策略：

| 边界策略 | 视觉与行为特征 | 最适合的产品与场景 | 严禁误用 |
|---|---|---|---|
| **1. 自然连续流（Seamless Flow）** | 顶栏与页面共享同一画布底色，静止时无分割线，仅靠留白分组 | 编辑阅读、温润消费 App、简洁表单、轻量设置页 | 滚动后内容穿过透明顶栏导致文字重影 |
| **2. 背景贯通延伸（Full-Bleed Backdrop）** | 封面图、地图、渐变头图或主画布完整铺满至状态栏/底部边缘 | 媒体播放、详情头图、地图、游戏、沉浸消费页 | 未给顶栏文字加暗色保护层导致看不清状态栏 |
| **3. 清晰硬边界（Crisp 1px Hairline）** | 明确 `1px` 细分割线区分工作区、侧栏、表头与检查器 | B 端企业后台、IDE、表格工具、专业创作软件、财务系统 | 强行用厚重阴影或模糊替代清晰结构边 |
| **4. 滚动触发显现（Scroll-Aware Hairline / Elevation）** | 滚顶 `scrollTop === 0` 时无缝融为一体，一旦向下滚动平滑浮现 `1px` 细线或极轻阴影 | 现代 Web 应用、iOS/macOS 原生页、SaaS 文档页 | 滚动瞬间生硬闪现重阴影 |
| **5. 渐进边缘羽化（Progressive Fade / Scrim）** | 内容滚入悬浮底栏或顶部控制岛背后时，通过短距同色渐变罩柔和消隐 | 悬浮胶囊 Tab Bar（如 iOS 26）、沉浸流式内容页、聊天输入区 | 羽化区域过大糊掉半行可读正文 |
| **6. 吸顶锚定（Sticky Section / Filter Bar）** | 关键列头、字母索引或筛选栏滚至顶栏下沿精准吸附并承接背景色 | 长表格、通讯录、商品列表、多期账单 | 多个吸顶层叠加占掉半个手机屏幕 |
| **7. 半透明系统材质（Liquid Glass / Mica / Acrylic）** | 悬浮导航与控制层透出下方滚动光影（遵守平台原生规范与对比度底线） | iOS 26 悬浮控制层、macOS 侧栏、Windows 瞬态浮层 | 把正文列表或大面积普通卡片做成毛玻璃 |
| **8. 动态收缩与展开（Collapsible Chrome）** | 向下沉浸浏览时顶/底栏平滑收起让出视野，轻微上滑即时恢复 | 长文阅读、图库瀑布流、短视频/信息流、地图浏览 | 工具类/高频导航页乱收起导航让用户找不到入口 |

## 3. 边界验收快速红灯测试

- [ ] 列表滚到最末尾，最后一项下方是否留出了 `底栏高度 + safe-area-inset-bottom + 16px` 呼吸空间？
- [ ] 向下滚动 100px 后，页面正文是否与顶栏标题/按钮发生重叠重影？
- [ ] 顶部导航、中间画布、底部栏的色彩与材质是否属于同一视觉世界，而不是生硬拼贴的三段？
- [ ] 键盘聚焦底部输入框或打开 Modal 时，页面高度与滚动是否稳定无穿帮？
