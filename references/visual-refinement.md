# High-Impact Visual Refinement (微调精修机制)

真正把产品从“勉强可用”拉升到“精致可靠”的，往往不是推倒重来，而是**用极小改动成本消除 5–10 处高影响力的视觉与空间瑕疵**。面对已有设计稿、半成品或成熟产品局部优化时，优先执行本精修雷达。

---

## 1. 二十项高影响力细节精修雷达

在真实运行截图（全局视图 + 局部 2× 放大检查）中逐项扫描：

| 分类 | 精修检查点 | 常见粗糙表现 | 精准微调手法 |
|---|---|---|---|
| **排版与文字** | 1. **字体基线对齐** | 大字数值与小字单位、标题与右侧辅助文字底部飘移 | 使用 `align-items: baseline` 或按大写字母高度光学居中 |
| | 2. **字重层级关系** | 全页都是 Regular 400 或全员 Bold 700，分不出主次 | 建立清晰的 2 级字重差（如标题 `600` 配正文 `400`，数据 `600` 配标签 `400/500`） |
| | 3. **数字排列工艺** | 金额、倒计时、表格列宽随数字变动左右抖动；货币符居中偏右 | 开启 `tabular-nums`；表列右对齐；大字居中金额弱化并微偏货币符号 |
| **图标与比例** | 4. **图标视觉重心** | 播放三角、箭头、自定义矢量在圆框里看起来歪了 | 播放三角向右偏移 ~1/6 宽；按视觉质量中心校准而非外框中心 |
| | 5. **图文比例与间距** | 图标比旁边字大一圈，或离文字仅 2px / 远达 14px | 正文 14–15px 配 `16–18px` 图标，间距稳定 `6–8px`，首行垂直居中 |
| **留白与边界** | 6. **光学对齐** | 左侧图标边缘或大标题首字母视觉缩进感不一致 | 校准阅读左轴线（评论正文对齐用户名边缘；列表图标占固定列轨） |
| | 7. **组件内部留白** | 卡片上松下挤、弹窗底部按钮离边比左右边距窄 | 四周留白光学均衡；按钮区与内容区分隔清晰且底部留白到位 |
| | 8. **边框粗细与必要性** | 到处都是深色 1–2px 粗边框，或卡片里再套边框 | 删除非必要边框，改用极细低对比描边（`rgba(..., 0.08)`）或留白/色阶区隔 |
| | 9. **圆角比例与嵌套关系** | 按钮圆角比外框大，或内外相同圆角拐角显厚薄不均 | 严格套用同心圆角 $R_{\text{outer}} = R_{\text{inner}} + \text{padding}$ |
| | 10. **阴影层次** | 默认脏灰单层重阴影，或暗色模式硬套黑阴影 | 亮色改用“1px 边 + 接触影 + 柔散射影”；暗色去掉黑影改表面提亮 + 顶边微光 |
| | 11. **分割线位置** | 通栏硬分割线把列表劈碎，或分割线紧贴文字仅 2px | 列表改用缩进对齐正文左缘的细分割线（Inset Divider），并保持 ≥8–12px 呼吸距 |
| **构图与节奏** | 12. **内容密度校准** | B 端数据页虚留大片空白，或消费阅读页塞满密字 | 按产品类型匹配密度（工具/数据紧凑高效，阅读/消费舒展从容） |
| | 13. **页面视觉重心** | 首屏处处抢眼或重心沉在下半屏 | 压暗 80% 辅助信息权重，让核心数值/标题/主操作形成唯一落点 |
| | 14. **图片裁切与构图** | 人像切头、商品偏边、异比例拉伸变形、白底图融入白背景 | 固定 `aspect-ratio` + `object-cover` + 合理 `object-position`；白底图加极细 `1px` 内描边 |
| | 15. **页面上下边界衔接** | 顶栏、内容区、底栏像三块硬拼的异色积木 | 按 [navigation-and-boundaries.md](./navigation-and-boundaries.md) 统一材质、滚动显现细线与底部安全留白 |
| | 16. **按钮与邻近元素关系** | 提交按钮紧贴输入框（<6px）或飘离所属表单过远（>24px） | 紧相关操作与字段保持 `12–16px`，弹窗底部按钮组右/全宽整齐锚定 |
| | 17. **组件节奏变化** | 全页从头到尾都是等宽等高卡片，机械单调 | 建立疏密节奏（顶部聚焦摘要 + 中段清晰列表/主工作区 + 克制次级区） |
| | 18. **非必要视觉噪声** | 装饰圆点、无意义角标、冗余英文小副标、多余底盒 | 逐个做“删掉测试”：删掉后信息未损失即永久移除 |
| **动态微修** | 19. **弹窗/菜单动画起点** | 点击右上角按钮，菜单却从屏幕正中央淡出 | 校准 `transform-origin` 至触发按钮锚点，建立空间因果联系 |
| | 20. **静态与交互态一致性** | 按钮按压无回馈、输入框聚焦无变化、切 Loading 宽度跳动 | 补全按压态、`:focus-visible` 焦点环与锁宽 Loading 占位 |

## 2. 高杠杆精修优先序列（投入最小、提质最明显）

当只能做局部微调或在初版完成后执行精修轮次时，优先按以下顺序出手：
1. **做减法**：删掉 1–2 层多余嵌套边框/无用容器/装饰小胶囊和背景杂色。
2. **拉层级**：加大主标题/核心数值与次级辅助文字的字号/字重/明度对比，统一 `tabular-nums`。
3. **校对齐**：把歪掉的左轴线、近切边（1–3px）、不等四周留白与同心圆角一次拉齐。
4. **理边界**：修好顶栏滚动衔接、底栏防遮挡间距、安全区与弹窗遮罩景深。
5. **润动效**：修正菜单/弹窗的 `transform-origin` 与收起速度，把生硬闪现改成顺滑因果过渡。

---

## 3. 精修效果验证铁律

每次微调完成后必须对比**修改前 vs 修改后真实截图**：如果某项视觉微调没有让信息更清晰、构图更舒展或操作更顺手，甚至反而增加了干扰，**立刻撤销回退**。
