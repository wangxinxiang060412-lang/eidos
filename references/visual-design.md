## 1. 六大经过对比度验证的产品审美起点原型

> 仅在 **0→1 新项目（用户授权配色）** 或 **用户确认调整配色** 时择一作为起点并按品牌定制；禁止用同一套原型套全部产品。

### 原型 A：瑞士精密 / 效率工具（Swiss Precision）
- **适用**：开发者工具、项目管理、SaaS 工作台、效率 App。
- **核心气质**：秩序、锋利、克制、高信息信噪比。
- **亮色阶梯**：Canvas `#F8F9FA` → Surface `#FFFFFF` → Raised `#FFFFFF`（+精细描边）→ Ink `#111318` / `#475467` / `#667085`（全阶对比度 ≥ 4.5:1）→ Hairline `#E4E7EC` → Accent（择一）钴蓝 `#2563EB` / 深松绿 `#0F766E` / 朱红 `#DC2626`。
- **暗色阶梯**：Canvas `#0D0F12` → Surface `#14171D` → Raised `#1C2029` → Overlay `#242936` → Ink `#F3F5F8` / `#A4ACB9` / `#858E9E`（在 Raised 表面仍 ≥ 4.5:1）→ Hairline `rgba(255,255,255,0.08)` + 顶边微光 `inset 0 1px 0 rgba(255,255,255,0.06)` → 实心按钮主色保持 `#2563EB`（配白字 ≥ 5.1:1），暗底链接/图标强调色提亮为 `#60A5FA`（≥ 6.4:1）。
- **几何参数**：控件圆角 `6–8px`，容器圆角 `10–12px`，字号紧凑精准（正文 `14px`）。

### 原型 B：温润触感 / 消费与编辑工艺（Warm Tactile Editorial）
- **适用**：笔记、阅读、生活消费、咖啡/轻旅、播客、独立内容社区、小程序。
- **核心气质**：人性化、有纸感与温度、舒展不冰冷。
- **亮色阶梯**：Canvas `#FAF8F5`（微暖米纸，非刺眼纯白）→ Surface `#FFFFFF` 或 `#F3EFE9` → Ink `#1E1A17`（深浓咖黑）/ `#5C534A` / `#70665C`（全阶 ≥ 5:1）→ Hairline `#E6DFD5` → Accent 陶土橙 `#B94E2A` / 鼠尾草绿 `#3D6B57` / 琥珀 `#B45309`（配白字均 ≥ 4.5:1）。
- **暗色阶梯**：Canvas `#141210` → Surface `#1D1A17` → Raised `#27231F` → Ink `#F4EFEA` / `#B5ACA2` → Hairline `rgba(255,245,235,0.09)`。
- **几何参数**：圆角柔和 `10–16px`，行高舒展（正文 `15–16px`, `lh 1.6`）。

### 原型 C：金融与数据可信（Institutional Clarity）
- **适用**：理财/证券、支付账单、医疗健康、企业 BI 报表。
- **核心气质**：稳健、精确、零歧义、高对比数据可读性。
- **亮色阶梯**：Canvas `#F5F7FA` → Surface `#FFFFFF` → Ink `#0F172A` / `#475569` / `#5B6B82`（在画布与白底均 ≥ 5:1）→ Hairline `#DCE3EC` → Accent 深海蓝 `#1D4ED8` 或墨蓝 `#0F4C81`。
- **数据铁律**：强制 `tabular-nums`；涨跌红绿遵循目标市场文化并配 `+`/`-` 与箭头冗余编码。

### 原型 D：专业创作画布（Studio Neutral）
- **适用**：摄影/图像/视频/音频剪辑、3D 建模、服装/平面设计工具、白板。
- **核心气质**：界面退居幕后，把 100% 色彩舞台让给用户作品。
- **色板铁律**：极低饱和度中性灰阶（暗色 `#161618` / `#1E1E21` / `#28282D`，亮色 `#F2F2F4` / `#FFFFFF`），除唯一焦点强调色外零彩色装饰；检查器控件紧凑高效（`28–32px`）。

### 原型 E：鲜明消费品牌 / 表现力（Expressive Consumer）
- **适用**：社交、教育、健身打卡、年轻消费品、Material 3 Expressive 风格应用。
- **核心气质**：有记忆点与活力，结构依然干净克制。
- **用法铁律**：使用同色系低饱和色块容器（Tonal Surface）表达品牌情绪，而非白底上乱洒多种高饱和彩虹色。

### 原型 F：沉浸式游戏与世界观（Atmospheric Game UI）
- **适用**：PC/主机/移动端游戏主菜单、HUD、背包、对话系统（详见 [platforms/game-ui.md](./platforms/game-ui.md)）。

## 2. 表面物理、光影与色度铁律

1. **60-30-10 色度纪律**：≥ 60% 低饱和中性画布与表面，~30% 次级结构与文字阶梯，≤ 10% 唯一核心强调色与真实语义状态色；避免大面积 `#000000` 与 `#FFFFFF` 硬撞。
2. **亮/暗模式物理分层**：
   - **亮色模式**：画布略灰、表面纯白 + 精细边界或三层柔和阴影（严禁脏灰重影 `0 10px 30px rgba(0,0,0,0.25)`）：
     ```css
     /* 卡片 / 轻浮层 */
     box-shadow: 0 0 0 1px rgba(15,23,42,0.06), 0 1px 2px rgba(15,23,42,0.05), 0 6px 16px -4px rgba(15,23,42,0.06);
     /* 弹层 / Popover / Modal */
     box-shadow: 0 0 0 1px rgba(15,23,42,0.08), 0 8px 24px -6px rgba(15,23,42,0.12), 0 20px 48px -12px rgba(15,23,42,0.10);
     ```
   - **暗色模式**：**靠更亮的表面阶梯表达高度，不靠黑阴影！**浮层比底面更浅一档，并叠加细腻顶边微光（`inset 0 1px 0 rgba(255,255,255,0.06–0.10)`）；主文字采用 `#F0F2F5` 防止纯白晕光；实心主按钮色保持与白字 ≥4.5:1，暗底文字强调色单独提亮。
   - **绝不同时堆“粗边框 + 重阴影”**；绝不允许多个半透明表面重叠发脏（No Onion Skin）。
3. **剪影与重心测试**：把整屏缩至 25% 或转黑白灰度看——唯一主视觉焦点、支撑内容区与呼吸留白必须一眼分明。
