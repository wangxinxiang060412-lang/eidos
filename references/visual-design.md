# Visual Design & Aesthetic Craft System

高级感不是堆留白、用极浅灰字、套磨砂玻璃或千篇一律的黑白极简；高级感来自**贴合产品气质的美术方向、精准的表面与对比度阶梯、严格的色度克制、以及毫厘不差的光学工艺**。

本文件将优秀设计师的直觉转化为**可复现、可计算、低参数模型也能稳定执行**的审美基线。

---

## 1. 六大产品审美原型（按产品定位择一，禁止千站一面）

在写任何样式前，先按产品属性选定一个原型（若用户有明确品牌 VI，则保留结构法则并替换品牌主色）：

### 原型 A：瑞士精密 / 效率工具（Swiss Precision）
- **适用**：开发者工具、项目管理、SaaS 工作台、效率 App（如 Linear / Stripe / Raycast 气质）。
- **核心气质**：秩序、锋利、克制、高信息信噪比。
- **亮色阶梯**：Canvas `#F8F9FA` → Surface `#FFFFFF` → Raised `#FFFFFF`（+精细描边）→ Ink `#111318` / `#475467` / `#667085`（全阶对比度 ≥ 4.5:1）→ Hairline `#E4E7EC` → Accent（择一）钴蓝 `#2563EB` / 深松绿 `#0F766E` / 朱红 `#DC2626`。
- **暗色阶梯**：Canvas `#0D0F12` → Surface `#14171D` → Raised `#1C2029` → Overlay `#242936` → Ink `#F3F5F8` / `#A4ACB9` / `#858E9E`（在 Raised 表面仍 ≥ 4.5:1）→ Hairline `rgba(255,255,255,0.08)` + 顶边微光 `inset 0 1px 0 rgba(255,255,255,0.06)` → 实心按钮主色保持 `#2563EB`（配白字 ≥ 5.1:1），暗底链接/图标强调色提亮为 `#60A5FA`（≥ 6.4:1）。
- **几何参数**：控件圆角 `6–8px`，容器圆角 `10–12px`，字号紧凑精准（正文 `14px`）。

### 原型 B：温润触感 / 消费与编辑工艺（Warm Tactile Editorial）
- **适用**：笔记、阅读、生活消费、咖啡/轻旅、播客、独立内容社区、小程序。
- **核心气质**：人性化、有纸感与温度、舒展不冰冷。
- **亮色阶梯**：Canvas `#FAF8F5`（微暖米纸，非刺眼纯白）→ Surface `#FFFFFF` 或 `#F3EFE9` → Ink `#1E1A17`（深浓咖黑，非死黑 `#000`）/ `#5C534A` / `#70665C`（全阶 ≥ 5:1）→ Hairline `#E6DFD5` → Accent 陶土橙 `#B94E2A` / 鼠尾草绿 `#3D6B57` / 琥珀 `#B45309`（配白字均 ≥ 4.5:1）。
- **暗色阶梯**：Canvas `#141210` → Surface `#1D1A17` → Raised `#27231F` → Ink `#F4EFEA` / `#B5ACA2` → Hairline `rgba(255,245,235,0.09)`。
- **几何参数**：圆角柔和 `10–16px`，标题可配人文无衬线或克制衬线，行高舒展（正文 `15–16px`, `lh 1.6`）。

### 原型 C：金融与数据可信（Institutional Clarity）
- **适用**：理财/证券、支付账单、医疗健康、企业 BI 报表。
- **核心气质**：稳健、精确、零歧义、高对比数据可读性。
- **亮色阶梯**：Canvas `#F5F7FA` → Surface `#FFFFFF` → Ink `#0F172A` / `#475569` / `#5B6B82`（在画布与白底均 ≥ 5:1）→ Hairline `#DCE3EC` → Accent 深海蓝 `#1D4ED8` 或墨蓝 `#0F4C81`。
- **数字与语义色铁律**：所有金额、涨跌幅、表格列必须 `font-variant-numeric: tabular-nums`；涨跌红绿遵循目标市场文化（中国大陆/东亚证券红涨绿跌；欧美绿涨红跌），且**必须同时配 `+`/`-` 号或上下箭头**，绝不单靠颜色。

### 原型 D：专业创作画布（Studio Neutral）
- **适用**：图像/视频/音频剪辑、3D 建模、CAD、白板、设计工具。
- **核心气质**：界面本身完全退后，把 100% 色彩舞台让给用户的作品。
- **色板铁律**：采用极低饱和度的纯中性灰阶（暗色优先 `#161618` / `#1E1E21` / `#28282D`，亮色 `#F2F2F4` / `#FFFFFF`），除唯一选中/焦点强调色外界面零彩色装饰；高频参数面板保持高密度（控件高 `28–32px`）。

### 原型 E：鲜明消费品牌 / 表现力（Expressive Consumer）
- **适用**：社交、教育、健身打卡、年轻消费品、Material 3 Expressive 风格应用。
- **核心气质**：有记忆点与活力，但结构依然干净克制。
- **用法铁律**：使用**同色系低饱和色块容器（Tonal Surface）**承载品牌情绪，而非在白底上乱洒 7 种高饱和彩虹色；标题字形富有个性，正文保持清晰克制。

### 原型 F：沉浸式游戏与世界观（Atmospheric Game UI）
- **适用**：PC/主机/移动端游戏主菜单、HUD、背包、对话系统。
- **核心气质**：与游戏美术世界观、时代材质与光影完全一体（详见 [platforms/game-ui.md](./platforms/game-ui.md)），**严禁套用白底灰框 SaaS 样式**。

## 2. 审美铁律（“品味即数学”公式，低参数模型必守）

1. **60-30-10 色度纪律**：
   - **≥ 60%**：低饱和中性背景与主画布（提供视觉喘息与焦点对比）。
   - **~ 30%**：次级结构表面、文字阶梯与精细分隔线。
   - **≤ 10%**：品牌主强调色（仅用于主 CTA、当前选中项、关键数据焦点）与真实状态色（成功/警告/危险）。
   - **禁止纯黑与刺眼纯白硬撞**：避免 `#000000` 直接铺整屏（OLED 极黑场景除外），避免 `#FFFFFF` 叠加刺眼高饱和荧光色。
2. **亮色与暗色不是简单反色**：
   - **亮色模式层次**：画布略灰（如 `#F7F8FA`），卡片纯白（`#FFFFFF`）+ 极轻边界与双层柔和阴影。
   - **暗色模式层次**：**靠更亮的表面阶梯表达高度，不靠黑阴影！**越靠近用户的浮层（弹窗/下拉菜单）底色越浅一档，并配极细亮色上边缘高光（`rgba(255,255,255,0.06–0.10)`）模拟顶光。
   - **暗色文字降刺眼**：主文字用 `#F0F2F5`（约 93–95% 白）而非刺眼 `#FFFFFF`；饱和强调色在暗色下略微降低纯度、提高明度，避免在深底上发生视觉晕光（halation）。
3. **高级柔和阴影配方（禁止默认脏黑大阴影）**：
   - 严禁使用 `box-shadow: 0 10px 30px rgba(0,0,0,0.25)` 这类脏灰重阴影。
   - **轻浮层 / 卡片（Light Mode）**：用“1px 极细边界 + 贴底接触影 + 远距环境散射影”组合：
     ```css
     box-shadow:
       0 0 0 1px rgba(15, 23, 42, 0.06),
       0 1px 2px rgba(15, 23, 42, 0.05),
       0 6px 16px -4px rgba(15, 23, 42, 0.06);
     ```
   - **弹层 / Popover / Modal（Light Mode）**：
     ```css
     box-shadow:
       0 0 0 1px rgba(15, 23, 42, 0.08),
       0 8px 24px -6px rgba(15, 23, 42, 0.12),
       0 20px 48px -12px rgba(15, 23, 42, 0.10);
     ```
   - **绝不同时堆“重边框 + 重阴影”**：若已用色彩分层或柔和阴影清晰区隔，优先省略多余边框；若采用极简平面线框风，则用统一 1px 细腻描边配零阴影。
4. **图标工艺铁律（提炼自 Stageshow Craft）**：
   - **单一家族、单一线宽**：全项目只用 1 套图标库（iOS 用 SF Symbols、Android 用 Material Symbols，跨端/Web 按风格选 Phosphor / Tabler / Heroicons / Lucide 之一），同一区域保持统一尺寸（常见 `16px / 20px`）与统一描边粗细（`1.5px` 或 `1.75px`）。
   - **禁止混搭实心与线框**（除非明确用“未选中线框 → 选中实心”表达选中态）。
   - **小尺寸用实心**：`≤ 14px` 的微型指示图标或着色小方格内图标优先用实心风格，细描边会发虚。
   - **Emoji 是内容，不是 UI 图标**：严禁用 🚀✨🔥⚙️ 充当导航图标或功能按钮图标。
   - **禁止手画粗糙 SVG 替代标准图标**，禁止用单字母彩色方块伪造公司 Logo（无真实 Logo 时用干净文字 Wordmark）。
5. **杜绝无意义透明叠层（No Onion Skin）**：
   - 堆叠的标签、头像、浮层面板必须使用不透明表面或清晰底色隔离，避免多层半透明底叠加发脏。
   - 玻璃/毛玻璃材质仅用于明确覆盖在滚动内容或照片上方的**导航与浮动控制层**（遵守 Apple iOS 26 Liquid Glass 与 Windows Acrylic 的克制原则），绝不把大块正文列表做成毛玻璃。
6. **视觉重心与剪影测试**：
   - 把界面缩小到 25% 或眯起眼睛看：**3 秒内能否清楚分辨唯一主视觉焦点、次级内容区与安静留白？**如果整页像马赛克一样处处都在尖叫抢眼球，立刻降噪。
