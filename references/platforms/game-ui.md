# Platform Specification: Game UI, HUD & Interactive Systems

游戏 UI 是世界观、叙事、美术与战斗手感不可分割的一部分。**严禁把游戏主菜单、背包或结算页做成普通白底 SaaS 后台或互联网电商 App！**

---

## 1. 先理解游戏本体再动笔

动手设计前必须先明确 6 个游戏前提：
1. **世界观与美术风格**（写实科幻、中世纪奇幻、赛博像素、水墨国风、低多边形卡通……材质、字体、边角、动效与音效必须同源）。
2. **核心玩法与节奏**（高速动作/FPS 容错以毫秒计，回合制策略/卡牌允许高信息密度与悬停细读）。
3. **玩家视角与镜头**（第一人称、第三人称越肩、俯视角 ARPG、2D 横版）。
4. **战斗态 vs 非战斗态**（探索、激战、潜行、过场剧情对信息干扰的容忍度完全不同）。
5. **目标输入设备**（纯键鼠、纯手柄、键鼠/手柄无缝热切换、触屏虚拟摇杆）。
6. **屏幕形态与视距**（客厅 4K 电视 3 米远距阅读 vs PC 桌面 60cm vs 掌机 7 寸小屏）。

---

## 2. 游戏 UI 四象限选型（Diegetic / Spatial / Meta / Non-Diegetic）

| 象限 | 定义 | 典型范例 | 使用策略 |
|---|---|---|---|
| **Diegetic（叙事内/拟物）** | 物理存在于游戏世界内，角色与玩家都能看到 | 宇航服背脊血条、枪械剩余弹药数显、角色抬腕看表 | 沉浸感最强，但需确保高速战斗下仍可一眼读数 |
| **Spatial（空间锚定）** | 锚定在 3D 世界坐标但非角色可见实体 | 敌人头顶血条、任务 3D 方向路标、地面技能预警圈 | 控制同屏数量与远近缩放，避免遮挡目标本体 |
| **Meta（状态氛围层）** | 屏幕空间视觉/听觉反馈，映射角色生理或心理状态 | 濒死屏幕边缘暗角/脉动、受击方向红弧、冰冻霜边 | 严禁大面积血雾糊死视野影响玩家反击 |
| **Non-Diegetic（传统 HUD 浮层）** | 独立覆盖在屏幕边界的清晰信息层 | 角落生命/体力条、技能冷却栏、小地图、伤害数字 | 最快读数效率，优先用于高频高压核心战斗数据 |

## 3. Minimum Viable HUD（最小可行 HUD 原则）

1. **中心视野神圣不可侵犯**：屏幕中央战斗与准星区保持极度干净，核心常驻 HUD 贴近外缘安全区布局，并遵循视觉扫视分组（如左下状态/生存、右下技能/弹药、右上小地图/任务、顶部 Boss 血条与指南针）。
2. **情境自适应显隐（Contextual HUD）**：非战斗探索时自动淡化非必要数值（满血条、满体力、无冷却技能），受击/消耗/切换武器时立即响应浮现。
3. **动态背景可读性保障**：游戏画面随时在明暗交替（雪地亮白 ↔ 洞穴漆黑），任何裸露在 3D 画面上的 HUD 文字与图标必须带**细腻暗色外描边、柔和投影或低侵入暗色半透明背板（Scrim）**，绝不能在亮背景下隐身。
4. **高压战斗瞬间识别**：
   - 血量骤降、技能冷却完毕（CD Ready）、可处决/弹反提示、受击方向必须具备**视觉 + 音效 + 手柄震动**三通道协同反馈（遵循 **Xbox Accessibility Guidelines XAG 103** 冗余感官原则）。
   - 严禁纯靠绿/红区分敌我或稀有度，结合形状、轮廓线、标识符号与色盲友好预设。

## 4. 全系统专项审查清单

除战斗 HUD 外，逐项核对：
- **主菜单 / 存档 / 角色选择**：沉浸式入场，核心入口“继续游戏 / 新游戏 / 设置”主次极明确；覆盖存档或删档必须长按确认（Hold-to-Confirm）防手滑。
- **背包 / 装备 / 制造**：支持快捷对比（当前装备 vs 选中项并排高亮差值）、清晰分类筛选与排序、减少多级嵌套确认弹窗。
- **对话与剧情字幕**：默认提供半透明暗底字幕背景选项、说话人名字清晰区隔、字号可调、支持跳过/加速且不会误跳。
- **暂停 / 设置 / 加载 / 结算**：暂停即停时间与音频压低；设置页支持即时预览（改画质/音量/字幕大小实时生效）；结算界面节奏明快，支持一键跳过冗长动画直接再战。
- **教程与提示**：情境式内联轻提示优于打断节奏的长篇大论弹窗。

## 5. 多输入、安全区与引擎性能硬规范

1. **手柄焦点导航与键鼠无缝切换（XAG 112 & 113）**：
   - 任意菜单时刻必须有**高可见度焦点框**，D-Pad / 左摇杆方向移动符合空间直觉，绝无焦点丢失或死角。
   - 一旦检测到按键切换（键鼠 ↔ Xbox / PlayStation / Switch 手柄），所有按键图标（Glyphs）实时动态切换，且遵循玩家自定义键位映射（Key Rebinding）。
   - 切忌把 PC 鼠标悬停交互照搬给手柄，也切忌用“缓慢的虚拟手柄光标”敷衍原生主机体验。
2. **多宽高比与 HUD 安全区**：
   - 遵守 **Action Safe（90–95%）与 Title Safe** 安全边距，并在设置中提供玩家可调 HUD 安全区缩放。
   - 兼容 `16:9`、`16:10`（Steam Deck）、`21:9` 超宽屏（支持 HUD 居中锁 16:9 或贴边可选）及移动端异形屏避让。
3. **游戏 UI 渲染性能**：
   - Unity（UGUI / UI Toolkit）：动静分离 Canvas（高频跳动血条/伤害数字与静态外框分 Canvas 隔离，避免每帧触发全画布 `Rebuild`）；非交互图片关闭 `Raycast Target`；大背包用对象池与虚拟滚动；合并图集（Sprite Atlas）控制 Draw Call。
   - Unreal（UMG / CommonUI）：优先用事件驱动更新属性，**严禁在蓝图 Property Binding / `Event Tick` 里每帧轮询刷新 UI 文本**；手柄导航优先使用 **CommonUI** 激活栈管理焦点与多平台键标。
