# Domain Specification: Smart Devices, Car HMI, TV & IoT Terminals

适用于智能车载中控/仪表（Automotive HMI）、智能电视与投影（10-Foot UI）、智能手表/穿戴设备（Wearables）、智能家居中控面板及线下自助终端（Kiosks）。
**核心铁律：绝不能把手机或桌面网页缩小/放大直接塞进特种硬件终端——必须围绕视距、扫视时间、输入方式与物理安全重构界面。**

---

## 1. 四类智能终端核心人因约束矩阵

| 终端类型 | 典型视距与注意力 | 主输入方式 | 不可违背的交互与视觉底线 |
|---|---|---|---|
| **车载 HMI（中控/仪表）** | 60–80cm，**驾驶安全第一**：单次扫视 ≤ 1.5–2 秒 | 粗粒度触控（颠簸环境）+ 语音 + 方向盘物理键/旋钮 | 超大触控热区 **≥ 60–76px**（高频空调/导航/切歌常驻边缘盲操区）；深色防夜间眩光 + 强光高对比日间模式；**极简文字、禁止行驶中弹出复杂长表单与密集列表**；主次信息层级极少（≤3 级） |
| **智能电视 / 投影（10-Foot UI）** | 2.5–3.5 米远距客厅观看 | 遥控器五向键（上下左右 + OK + 返回）+ 语音 | 严格遵守 **5% 过扫描安全区（Overscan Safe Area）**；正文 **≥ 24–28px**（1080p 基准）；**极显眼焦点状态**（放大 `scale 1.05–1.08` + 明亮外框/投影，绝不能让用户找不到焦点在哪）；菜单层级浅平（≤2–3 层），减少横向与纵向混合死胡同 |
| **智能手表 / 穿戴（Wearables）** | 25–35cm，抬腕扫视 **≤ 3 秒** | 小屏单指触控 + 表冠旋钮（Digital Crown）+ 侧键 | **一屏一件事（Glanceable）**：纯黑 OLED 底省电且消隐表盘黑边；圆形表盘四周留出弧形内边距防角落文字被切；单次操作 ≤ 2 步完成；避免小键盘打字，改用快捷回复/语音/表冠滚动 |
| **智能家居墙面屏 / 线下 Kiosk** | 40–100cm，站立快速操作、低频陌生用户为主 | 单点触控 / 扫码 / NFC | 零学习成本，首屏直给最核心 3–6 个大按钮（≥ 64–80px）；考虑公共终端隐私与**超时自动重置回首页**（清除上一位用户态）；清晰无障碍高度与语音/视觉双提示 |

## 2. 跨硬件终端通用设计规则

1. **物理环境自适应**：结合昼夜光感（自动切换日间高对比/夜间护眼暗色）、屏幕形态（圆形/超宽带鱼屏/副驾屏）与硬件刷新率合理控制动画复杂度。
2. **输入反馈多通道冗余**：脱离鼠标悬停后，焦点移动、旋钮刻度、关键确认与告警必须结合**高辨识度视觉态 + 恰当触觉/震动反馈 + 克制提示音**。
3. **离网与硬件异常韧性**：车机进隧道、IoT 设备断联、打印机缺纸或传感器离线时，立即展示清晰的本地状态与可降级操作，绝不无限转圈卡死界面。
