# Platform Specification: Desktop Applications (macOS 26 & Windows 11 Fluent 2)

参考标准：Apple macOS 26 HIG、Microsoft Windows 11 **Fluent 2** Design System，同时覆盖原生（AppKit / SwiftUI / WinUI 3）与跨端桌面框架（Electron / Tauri / Qt）。

---

## 1. 桌面端核心差异：效率、精度、多窗口与快捷键

严禁把移动端大按钮单栏布局简单拉宽冒充桌面应用：
1. **信息密度与精准控件**：鼠标指针精度高，常规控件高度为 **28–36px**，列表行高 **32–44px**，正文 **13–14px**；充分利用左中右多栏布局（Sidebar + List + Detail/Inspector）减少整页跳转。
2. **键盘优先（Keyboard-First）**：
   - 完整实现标准快捷键：macOS 用 `⌘`（`⌘N` 新建、`⌘S` 保存、`⌘Z/⇧⌘Z` 撤销重做、`⌘F` 搜索、`⌘K` 命令面板、`⌘,` 设置、`⌘W` 关窗）；Windows/Linux 自动映射为 `Ctrl`。
   - 列表支持上下方向键浏览、回车打开、`Space` 快速预览、`Delete/Backspace` 删除（带撤销）。
3. **Hover 与右键上下文菜单**：
   - 高频行操作（编辑、置顶、复制、删除）可在 Hover 时克制显现，避免 50 行列表满屏重复按钮。
   - 所有对象与画布支持符合直觉的右键上下文菜单（Context Menu），并与顶部菜单栏项保持一致。
4. **自由窗口缩放与失焦态**：
   - 设置合理的最小窗口尺寸（如 `960×640` 或针对紧凑工具定制），自由拉伸时侧栏固定宽、主工作区弹性伸展。
   - **窗口失焦态（Inactive Window）**：窗口失去焦点时，标题栏、选区高亮与材质适当降饱和/变淡，让用户一眼区分当前活跃窗口。

## 2. 平台原生气质适配（macOS vs Windows）

| 维度 | macOS (26 HIG) | Windows 11 (Fluent 2) |
|---|---|---|
| **窗口控制按钮** | 左上角红黄绿交通灯（Traffic Lights），自定义标题栏必须留足左侧安全距（~78px） | 右上角最小化/最大化/关闭按钮，自定义标题栏右侧留足系统按钮区 |
| **弹窗主按钮位置** | 确认/主操作在**右侧**，取消在左侧 | 确认/主操作通常在**左侧**（或遵循应用内一致约定，不混用） |
| **系统材质** | 浮动侧栏与工具栏采用 Liquid Glass / 窗口半透明材质，主内容区实底 | 主窗口背景与标题栏采用 **Mica / Mica Alt**（低开销随壁纸微染，失焦退回纯中性色）；**Acrylic** 严格仅限右键菜单、Flyout、弹窗等瞬态浮层，绝不两块 Acrylic 紧贴叠加 |
| **默认字体与圆角** | SF Pro + PingFang SC；圆角随系统窗口圆角同心协调 | Segoe UI Variable + 微软雅黑；小控件 `4–6px`，窗口/浮层 `8px` |
| **菜单体系** | 接入系统顶部全局 Menu Bar（File / Edit / View / Window / Help） | 应用内标题栏紧凑菜单/工具条 + 清晰系统托盘行为 |

## 3. Electron / Tauri 桌面化防“套壳网页味”检查

- 禁止网页感整页文本误选（给非正文区域工具栏/侧栏设 `user-select: none`，正文与可复制数据保留可选）。
- 禁用无意义的浏览器右键“检查元素/刷新”与拖拽图片新开页面；接入原生系统文件选择器、原生通知、原生拖放（Drag & Drop 文件进窗口）与窗口尺寸记忆。
