# Domain Specification: Data Analytics Platforms & Big-Screen Dashboards

适用于 BI 分析平台、实时监控中心、运营驾驶舱与指挥大屏（Data Visualization Big Screens）。
**核心铁律：分析平台与大屏的首要价值是洞察关系、比较效率与决策支持——严禁堆砌华而不实的 3D 特效、科技边框光效与无法读数的装饰图表。**

---

## 1. 桌面 BI 分析平台 vs 监控大屏的关键差异

| 维度 | 桌面 BI / 自助数据分析平台 | 监控中心 / 可视化大屏（1080p / 4K / 拼接屏） |
|---|---|---|
| **视距与阅读方式** | 50–70cm 近距交互探索、下钻、筛选、导出 | 2–5m 远距扫视、快速捕捉异常态势 |
| **主题极性** | 亮色为主（久视舒适、便于截图入报告）+ 可选暗色 | 暗色深低饱和基底为主（防大屏刺眼炫光，突出亮色告警与核心指标） |
| **交互重心** | 时间区间对比、多维钻取（Drill-down）、联动过滤、异常归因、下载明细 | 极简零干扰：自动定时刷新、状态轮播可选、异常告警强视觉锚定 |
| **排版基准** | 常规 `12–14px` 标签，`24–32px` 关键指标 | **远距大字号**：辅助标 `≥16–18px`（1080p 基准），主指标 `40–72px+`，极高对比度 |

## 2. 决策导向的布局与视觉纪律

1. **视觉黄金分区（倒金字塔信息架构）**：
   - **第一层（核心北极星 / 实时态势）**：占主视觉焦点（顶部或中央主区），一眼回答“整体正不正常？离目标差多少？”。
   - **第二层（关键趋势与归因对比）**：围绕主指标展开同比/环比走势、核心维度拆解与转化漏斗。
   - **第三层（异常明细与告警队列）**：按严重度排序的高亮异常列表，支撑决策者立刻定位动作。
2. **联动与比较效率（BI 平台必做）**：
   - 全局时间控制器统一作用于同页图表，清晰标明当前统计口径、时区与“最后更新于 HH:mm:ss”。
   - 点击某一维度（如某地区/渠道）支持跨图表高亮联动或一键下钻到明细表。
3. **杜绝“赛博大屏模板病”**：
   - 严禁给每张图表四角硬加发光机甲括号、满屏无意义粒子动效、旋转 3D 地球遮挡数据标签、或把 15 种高饱和彩虹色铺满屏幕。
   - **克制色阶原则**：正常业务数据保持平静的中性蓝/青/灰单色系阶梯；把高对比橙/红严格留给**真正触发阈值的告警与异常下跌**，让异常在 1 秒内跳出画面。
4. **实时刷新稳定性**：
   - 定时拉取数据更新时保持坐标轴与容器高度稳定，数字开启 `tabular-nums` 平滑更新（绝不整页闪烁重载）；数据断流或延迟超过阈值时明确提示“数据已延迟 X 分钟”，绝不假装实时正常。
