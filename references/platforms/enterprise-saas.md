# Domain Specification: B-End Enterprise, SaaS & Pro Productivity Tools

适用于企业管理后台、ERP/CRM/OA、研发协同、低代码平台、财务/供应链系统与专业生产力工具。
**核心铁律：B 端与专业工具追求信息密度、数据准确性、操作效率与复杂流程可控性——严禁盲目套用 C 端营销风的大面积留白、巨型 Hero 或装饰卡片。**

---

## 1. 信息密度与工作区结构

1. **三档密度意识**：常规工作区行高 `36–44px`、表单与工具栏控件高 `32–36px`、表格紧凑模式可至 `32px`；高密度数据表格提供“紧凑 / 标准”密度切换更佳。
2. **首屏直达工作区**：禁止把顶部 40% 空间浪费在欢迎标语或巨大宣传横幅上；顶栏紧凑（`48–56px`），左侧持久化可折叠导航栏（`200–240px`），核心筛选区与主表/主画布首屏立即可操作。
3. **减少整页跳转，善用多栏与抽屉**：
   - 列表查看详情优先采用 **右侧抽屉（Side Drawer）** 或 **Master-Detail 双栏**，让业务员核对 30 条单据时不断流、不丢失列表筛选和滚动位。
   - 复杂配置表单按语义分栏或分步骤（Step Form），支持草稿自动保存与字段级即时校验。

---

## 2. 高频效率与复杂业务流程

1. **表格是一等公民**：
   - 支持列宽调整、固定首尾列（名称列左固定、操作列右固定）、吸顶表头、多条件组合筛选、排序与 URL 查询同步。
   - **批量操作（Bulk Actions）**：勾选多条记录后浮现清晰上下文批量操作条（显示已选条数 + 批量审批/导出/删除 + 取消选择）。
   - 数值/金额严格右对齐 + `tabular-nums`，状态列统一语义色点 + 清晰短文案（不用巨大彩色厚胶囊）。
2. **键盘效率与快捷键**：专业 SaaS 与生产力工具支持 `Cmd/Ctrl + K` 全局命令面板、`/` 聚焦搜索、`Esc` 关闭抽屉、表格上下键导航与快捷创建，降低每天数千次鼠标移动疲劳。
3. **权限、审计与高风险防护**：
   - 无权限按钮明确隐藏或置灰并配 Tooltip 说明所需角色（绝不点击后才甩冷冰冰 403）。
   - 涉及资金、审批流转、批量删除、生产配置发布的操作，明确展示影响条数与后果，支持二次确认（极高危输入目标名确认）与操作日志可追溯。
4. **导出与长耗时异步任务**：大数据导出、批量导入校验采用非阻断后台任务队列提示（进度条 + 完成通知/下载入口），不锁死用户切页继续干活。
