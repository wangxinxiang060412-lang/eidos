# Information Architecture & Navigation

信息架构（IA）的核心是**让用户随时知道自己在哪、能去哪、怎么回来**，并以最短的合理路径完成任务，而不是用一堆孤立页面凑功能感。

---

## 1. 功能五级分层模型

开始设计页面前，先将所有功能归入以下 5 层：

| 层级 | 定义 | 承载载体（按平台适配） |
|---|---|---|
| **L1 一级核心功能** | 决定产品定位的 3–5 个顶级空间 | 移动端 Bottom Tab Bar（3–5 项）；桌面/Web 左侧 Sidebar 或顶栏主导航 |
| **L2 二级业务功能** | 一级空间内的主视图切换、分类与列表 | 分段控件（Segmented Control）、顶部 Tabs、二级侧栏、筛选条 |
| **L3 三级详情与配置** | 具体对象详情、编辑页、子设置 | Push 详情页、右侧详情分栏（Master-Detail，平板/桌面端优先） |
| **T 临时操作界面** | 聚焦型单任务：新建、快速筛选、分享、支付确认 | Bottom Sheet（移动）、Modal Dialog（聚焦阻断）、Popover/Menu（轻量上下文） |
| **U 辅助与低频功能** | 帮助中心、法务条款、关于、日志导出、账号注销 | 个人中心/设置二级页、溢出菜单（`…`）、页脚链接 |

---

## 2. 路径步数与深度原则

- **高频核心任务**：原则上控制在 **1–3 次关键操作**内完成或抵达主工作区（如看列表 → 点记录 → 执行操作）。
- **专业复杂功能**：允许更深层级（如多级项目/文件目录、专业设置树），但**严禁迷路**——必须提供面包屑（Breadcrumb）、清晰导航标题、层级指示与一键回顶层入口。
- **反形式主义铁律**：不要为了机械遵守“三次点击定律”把 20 个入口全塞进首页导致信息过载；也不要为了显得“流程严谨”强行插毫无意义的中间确认页或过渡引导页。

---

## 3. 页面跳转 vs 局部承载决策矩阵

在决定新建一个路由页面之前，先按此表判断是否应改为更轻的承载方式：

| 场景特征 | 推荐载体 | 禁止误用 |
|---|---|---|
| 选项 ≤6 个、无复杂表单、强依赖触发元素上下文 | **Popover / Dropdown Menu** | 跳一个全屏页面只为选 3 个选项 |
| 移动端单手快速操作、多维筛选、分享面板、轻量详情预览 | **Bottom Sheet（支持拖拽高度与手势下滑关闭）** | 用居中硬弹窗强塞半屏列表 |
| 列表页点开查看详情，且用户会高频在多条记录间来回切换（Web/桌面/平板） | **Master-Detail 双栏或右侧 Drawer** | 每次看详情全屏跳转、返回后丢失列表上下文 |
| 仅展开补充说明、次级参数、单条回复 | **就地折叠展开（Accordion / Inline Edit）** | 弹全屏 Modal 只为改一个标题 |
| 不可逆高风险确认、需中断当前流的独立审批/登录 | **Modal Dialog**（明确取消与后果） | 用于普通提示或展示长文章 |
| 独立长流程、深度编辑、需要独立 URL 分享/收藏 | **独立完整页面（Route）** | 把整个多步骤编辑器塞进小弹窗 |

## 4. 导航一致性与健壮性审查 10 条

1. **位置感知**：当前激活导航项有清晰选中态（不仅靠颜色，还带字重/填充/图标实心化或指示条），页面标题与触发入口文案一致。
2. **返回状态保留**：从详情页返回列表页时，**必须保留原滚动位置、筛选条件、排序与搜索词**（严禁每次返回都重置到顶部并重新拉全量数据）。
3. **跨页导航一致**：同一层级页面的返回按钮位置、页头高度、操作区顺序与关闭语义必须统一。
4. **杜绝循环与死胡同**：检查是否存在 A→B→A 无限入栈，或某些子页没有返回/首页入口把用户困死。
5. **消除重复入口**：同一核心能力不应在同屏顶栏、侧栏、快捷卡片、底栏同时出现 3–4 个重复入口（上下文直达按钮除外，需主次清晰）。
6. **系统返回一致**：
   - iOS 边缘右滑返回（Swipe Back）与应用左上角返回逻辑一致，支持手势跟手中断。
   - Android 预测性返回（Predictive Back）正确退出弹层/退栈，在根页不误退出或给出预期行为。
   - Web 浏览器前进/后退与 URL Query/Hash 状态同步，筛选/分页/弹窗（若值得分享）刷新不丢失。
7. **深层链接（Deep Link）可用**：从通知、分享链接或直接粘贴 URL 进入三级详情页时，能正常加载数据；点击返回时若无历史栈，优雅回退至合理的父级列表或首页，而不是白屏或无响应。
8. **未保存离开拦截**：表单/编辑器有未保存修改时，点击返回、切换 Tab 或关闭弹层前必须提示“放弃更改 / 继续编辑 / 保存草稿”。
9. **Tab 切换行为**：移动端切 Tab 保留各 Tab 独立子栈；再次点击当前激活 Tab 返回该页顶部（或回到根视图）。
10. **无意义中间页清除**：合并只有 1–2 个按钮的中转门户页，把最有价值的内容直接前置。
