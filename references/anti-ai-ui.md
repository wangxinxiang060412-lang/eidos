# Full-Stack Anti-AI Design Audit (UI · Icons · Type · Motion · Content)

本规范不仅排查常见 AI 视觉模板病，还全面覆盖**交互、图标、排版、动效、数据展示与内容组织**中的机械化 AI 痕迹（文案类反模板细则同步见 [ux-writing.md](./ux-writing.md)）。

**核心原则：审查的关键不是某个元素是否出现，而是它是否有存在的必要。**胶囊、卡片、圆角、渐变本身并非绝对禁令——只要具备明确的交互语义、品牌价值或功能意义即可保留；但禁止无理由堆砌，也严禁只靠换配色/字体/圆角伪装原创性。

## 26 项全栈 AI 模板病精准诊断与修复表

| 类别 | # | AI 模板病特征 | 合理例外 | 外科修复方案 |
|---|---|---|---|---|
| **容器与胶囊** | 1 | **滥用胶囊标签（Pill Soup）** | 真实可交互 Filter Chip、每行 ≤1–2 个高优先级状态标 | 普通元信息改纯文字 + 间点（`·`）或次级字色；用排版层级而非药丸盒 |
| | 2 | **用小椭圆 / 圆弧矩形包裹普通说明文字** | 可点击公告链接或明确功能入口 | 剥掉外框，直接通过字号、字重、颜色、对齐与留白建立层级 |
| | 3 | **无意义的状态徽章与分类标签** | 真正区分异常/待办/关键状态的语义标 | 仅在用户需要据此筛选或决策时保留；常规正常态默认静默不贴标 |
| | 4 | **全站千篇一律卡片网格** | 独立异构实体画廊（商品/作品/模板） | 按内容性质改用列表行、分组表、数据表格或开放画布 |
| | 5 | **卡片套卡片（Card-in-Card）** | 极少数含可拖拽子项的看板 | 去掉外层或内层边框，用 `16–24px` 留白或极浅色差区隔 |
| | 6 | **大量无意义边框与通栏分割线** | B 端高密度数据网格与硬边界工作台 | 优先留白分组与对齐；列表改用缩进细分割线（Inset Divider） |
| | 7 | **全员套用相同大圆角（Bubble Bloat）** | 主打圆润亲和力的儿童/情感品牌 | 按组件尺度与同心公式（$R_{\text{out}} = R_{\text{in}} + \text{pad}$）建立层次 |
| **色彩与材质** | 8 | **无意义渐变、背景光斑、外发光与玻璃拟态** | 悬浮于媒体之上的导航层材质 / 音乐封面氛围光 | 正文与业务面板还原高对比实底；清除背景漂浮模糊球 |
| | 9 | **默认紫蓝渐变配色（#6366F1 → #A855F7）** | 明确以紫蓝为品牌色的特定产品 | 按产品 8 维定位推导独立配色（存量项目改色前须获用户确认） |
| | 10 | **靠大量重阴影制造虚假层次** | 亮色浮层的多层克制柔影 | 亮色改用柔和三层轻影或 1px 细边二选一；暗色改表面明度阶梯 + 顶光 |
| | 11 | **用过度留白伪装高级感** | 艺术画册 / 高端品牌极简着陆页 | 按产品类型匹配真实信息密度（B 端/分析平台优先效率与一屏可读量） |
| **图标与装饰** | 12 | **每段普通内容前都硬塞装饰图标** | 提升扫描速度的一级导航/关键操作图标 | 删除不提供识别效率的装饰图标 |
| | 13 | **图标外机械套彩色圆形/圆角方底盒** | 真实应用头像、文件类型或核心一级大分类 | 剥掉彩色底盒，直接用克制单色线性/实心图标或纯文字层级 |
| | 14 | **盲目全员通用图标 / 混搭不同风格图标** | 同一导航内“未选中线框 → 选中实心” | 锁定单一家族、统一线宽与端帽；核心品牌与游戏界面可定制矢量 |
| | 15 | **AI 功能无脑配紫色 ✨ 星星/魔法棒** | 产品自身品牌图标恰好含星标 | 用具体功能动词与界面结果展示智能能力，而非贴星星贴纸 |
| **排版与文案** | 16 | **功能页顶部堆巨大空洞标题 + 废话副标题** | 品牌官网首屏 Hero | 工具/业务页紧凑顶栏直达工作区；标题已清晰时直接删掉解释副标题 |
| | 17 | **普通业务页塞营销标语与零碎英文小标签** | 国际通用专业缩写（API / FPS / SKU） | 用自然简洁的目标语言直述功能，绝不靠大写英文装饰装高级 |
| | 18 | **字号过小、字色过浅牺牲可读性** | 禁用态控件（仍需可辨识） | 严格守住 WCAG 2.2 AA（正文 ≥4.5:1，可读最小字号 ≥11–12px） |
| **布局与数据** | 19 | **所有页面采用完全相似的布局节奏** | 规范统一的同类详情模板页 | 按页面任务形成疏密与结构节奏变化，避免每页都是“顶头卡 + 三列卡” |
| | 20 | **看到数据就堆重复 KPI 卡片 / 机械 Bento Grid** | 官网特性总览或有明确主次比例的数据大盘 | 按 [data-visualization.md](./data-visualization.md) 选型：紧凑指标条、表格、趋势线、Sparkline |
| **动效与交互** | 21 | **每个页面机械套统一淡入上浮（Fade-Up）** | 首屏极克制的局部入场 | 按空间因果为不同组件定义差异化起止与时长，常规业务页直出不炫技 |
| | 22 | **弹窗/菜单/浮层突然闪现或瞬间消失** | `prefers-reduced-motion` 开启时的无位移切换 | 基于锚点设计快速、灵动、可打断的展开与收起过渡 |
| | 23 | **所有动画用完全一样的时长和缓动曲线** | 无例外 | 区分 Spatial 与 Effects，高频微反馈 80–160ms、空间转场 220–340ms |
| **真实与诚实** | 24 | **精美外壳下藏大量无效/空壳按钮** | 无例外（**P0 阻断**） | 100% 控件真实接线；缺后端依赖时诚实说明边界 |
| | 25 | **使用廉价假数据（John Doe / 99.99% Faster）** | 明确标注的交互沙盒示例数据 | 编写贴合真实中文/业务语境且经得起校验的数据 |
| | 26 | **伪造功能成功反馈（未真保存却弹“已同步”）** | 无例外（**P0 阻断**） | 反馈文案与真实程序状态 100% 一致，失败如实告知并保留用户输入 |

## 30 秒全栈“去 AI 味”红灯测试

若当前界面命中 **≥ 2 条**以下特征，立刻返工：
- [ ] 一屏内出现 ≥4 个包裹普通说明文字的小椭圆/胶囊，或 ≥4 个套了彩色圆角底盒的装饰图标？
- [ ] 页面标题下方有一句像“在这里发现并探索你的无限可能”一样的废话副标题？
- [ ] 存在卡片里面再套带边框卡片，或连续 4 张结构雷同的重复 KPI 卡片？
- [ ] 菜单/日期选择器点击后凭空瞬间闪现，或页面一打开整屏元素同步慢悠悠淡入上浮？
- [ ] 存在点下去无真实状态变化的筛选器/按钮，或未保存却弹窗谎称成功？
- [ ] 转成黑白灰度并缩至 25% 后，整页平铺直叙找不到唯一视觉焦点？
