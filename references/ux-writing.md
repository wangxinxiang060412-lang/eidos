# UX Writing & Interface Copy

界面文案就是交互本身。含糊的按钮、充满技术黑话的报错、油腻浮夸的 AI 营销词，会瞬间毁掉再精致的视觉设计。

---

## 1. 核心文案 6 条铁律

1. **按钮用“动作动词 + 具体对象”**：
   - 好：`保存草稿`、`导出 CSV`、`删除该项目`、`重新发送`、`移出团队`
   - 坏：`确定`、`提交`、`是`、`好的`、`执行操作`（尤其在破坏性确认弹窗中，严禁只写“确认 / 取消”，必须写明后果，如 `确认删除` vs `保留`！）
2. **术语全产品统一**：同一概念禁止在首页叫“工作区”、侧栏叫“空间”、设置页叫“团队组织”。建立微型产品词汇表并严格遵守。
3. **直白、短促、不废话**：能用 4 个字说清就绝不写 16 个字；删掉无信息量的客套前导词（如“温馨提示：您好，您可以点击下方按钮来进行……” → 直接写“点击下方按钮重新验证”）。
4. **讲人话，禁止泄漏后端黑话**：
   - 坏：`Error 422: Unprocessable Entity (token_expired)` / `null pointer exception`
   - 好：`登录状态已过期，请重新登录后继续保存`
5. **去机械化、去 AI 营销味**：
   - 严禁在工具/业务软件中滥用感叹号（`保存成功！！！` → `已保存`）、空洞吹捧（`极致赋能`、`重塑下一代工作流`、`无缝丝滑体验`、`Elevate your workflow`）与虚假社会证明。
6. **结果透明可预期**：涉及扣费、公开可见、发送通知或不可逆删除时，明确写明影响范围（如“发布后所有团队成员立即可见”、“将永久删除 3 条记录及附件，无法恢复”）。

## 2. 高频界面文案对照速查

| 场景 | 反例（机械 / 模糊 / AI 味） | 正例（自然 / 精准 / 可操作） |
|---|---|---|
| 空列表 | `暂无数据！快去开启你的高效之旅吧！` | `还没有项目` + 副文 `创建第一个项目以跟踪任务与进度` + 按钮 `新建项目` |
| 删除确认 | 标题 `提示` / 内容 `确定要删除吗？` / 按钮 `取消` `确定` | 标题 `删除“Q4 发布计划”？` / 内容 `关联的 12 条任务也会一并移除，此操作无法撤销。` / 按钮 `取消` `删除项目` |
| 表单校验 | `输入格式不正确` | `密码需至少 8 位，且包含字母和数字` |
| 断网报错 | `Network Error (-1009)` | `网络连接已断开，当前草稿已自动暂存本地。恢复网络后点击重试。` |
| 加载状态 | `正在努力加载中，请耐心等待哦~` | `正在同步账单…`（或直接骨架屏） |
| 权限说明 | `请求相机权限` | `用于扫描纸质发票并自动填入金额` |
| 搜索无果 | `No results found.` | `未找到与“差旅报销”相关的内容，试试缩短关键词或清除筛选条件` |

## 3. 标点、大小写与格式细节

- **中文界面**：操作按钮、菜单项、短标题末尾**不加句号**；完整多句说明使用正常全角中文标点；中英文或数字之间在排版引擎未自动处理时保持舒适可读间距（现代渲染已逐步支持 `text-autospace`，保持一致即可）。
- **英文界面**：按钮、菜单、表头与标题统一采用 **Sentence case**（`Create new project`，而非 `CREATE NEW PROJECT` 或到处 Title Case），可读性更高且更现代。
- **日期、货币与单位**：遵循目标地区习惯（中文 `2026年11月24日` 或 `11-24 14:30`，金额带千分位与两位小数 `¥1,280.00`）；相对时间（`刚刚`、`5 分钟前`）配合悬浮/详情可见精确时间戳。
