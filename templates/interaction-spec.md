## 2. 节拍与 Token 映射
| 阶段 | 变化属性（限合成属性） | Motion Token / 曲线与时长 | 备注 |
|---|---|---|---|
| 按压初态 | `transform: scale(0.98)` | `motion.instant` (`80–100ms`) | 指针按下即触发 |
| 主体展开 | `transform` + `opacity` | `motion.spatial.fast` (`180–220ms`) 或 `default` (`240–320ms`) | 前 30% 时长即达不透明，防幽灵叠脏 |
| 内容显现 | `opacity` | `motion.effect.fast` (`140ms`, 延迟 `40ms`) | 容器边绝不硬切文字 |
| 退出收起 | `transform` + `opacity` | `motion.spatial.exit` (`140–180ms`) | 零回弹干脆收尾 |

## 3. 帧级验收点
- [ ] 起始帧内容已就绪（无空壳白帧）
- [ ] 中间帧无边缘切字、无半透明叠脏、无锚点漂移（Anchor Drift）
- [ ] 落位帧零 1px 跳变与字形抖动
- [ ] 连点、半途打断与 `prefers-reduced-motion` 均实测通过
