# Bad Patterns: AI Slop, Broken UX & Exact Surgical Fixes

本文件收录最常见的失败案例，帮助 Agent 在生成前与审查时一眼识别并精准避坑。

---

## 反例 1：典型 AI 模板化“紫蓝渐变 + 胶囊汤 + 嵌套卡片”仪表盘

**坏表现**：
- 页面顶部硬放居中渐变大标语 `✨ AI-Powered Smart Workspace`，配一个带紫蓝渐变外发光的主按钮。
- 外层大卡片里套 4 张带边框的小卡片，每张小卡片里又放 3 个不同颜色的圆角小胶囊（`ACTIVE`、`PRO`、`UPDATED`），数据全用假数字 `99.9%`。
- 右上角 3 个时间筛选胶囊按钮（`7D / 30D / 1Y`）点下去什么都不会变。

**为什么不合格**：违反 Anti-AI-UI #1、#2、#4、#5、#9、#15 及红线 #3（假控件）。整页全员抢视觉权重，毫无业务密度与真实功能。

**外科修复**：
1. 删除居中营销 Hero 与 ✨ 胶囊；顶部改为 `56px` 紧凑工作台栏（页标题 + 真实可切换的时间分段控件 + 唯一实心纯色主 CTA）。
2. 去掉外层大边框，用画布与白底卡片的一层对比呈现核心趋势区，右侧明细改用干净列表行（零卡片套卡片）。
3. 删除装饰性英文大写胶囊，只保留真正反映异常状态的 1 个语义状态标识。
4. 为 `7D / 30D / 1Y` 接入真实过滤与重新汇总逻辑，数字全部启用 `tabular-nums`。

## 反例 2：假极简主义——低对比浅灰字 + 隐藏所有示能

**坏表现**：
- 白色背景上正文与副标题用 `#B0B5BD`（对比度仅 `2.0:1`），输入框没有边框也没有背景色差，用户找不到哪里能输入。
- 关键操作按钮被藏在 Hover 才出现的淡灰 `14×14px` 小图标里，手机端彻底点不到。

**为什么不合格**：违反 WCAG 2.2 SC 1.4.3 / 1.4.11 / 2.5.8 及“可用性优先于极简”裁决原则（P0/P1）。

**外科修复**：
1. 主正文调至 `#111318`（≥15:1），次要正文 `#525866`（≥7:1），最淡辅助文字不低于 `#667085`（≥4.8:1）。
2. 输入框明确提供 `1px` 可见边界（对比度 ≥3:1）或柔和浅灰底色 + 清晰的 `:focus-visible` 焦点环。
3. 移动端把高频操作常显或放入显式溢出菜单，按钮点击热区扩充至 `≥44×44px`。

## 反例 3：阻塞操作的慢速演示型动效与不可打断弹窗

**坏表现**：
- 点击 Tab 切换，整页先淡出 `400ms`、白屏停顿 `100ms`，再从右侧滑入 `600ms` 并剧烈弹簧回弹 3 次；切换期间给全屏加 `pointer-events: none` 锁死用户点击。
- 下拉筛选列表输入关键字变短时，Popover 上边缘跟着跳动（Anchor Drift）。

**为什么不合格**：把演示视频节奏误用于生产界面；违反 Doherty 阈值、可打断性与锚点不漂移原则。

**外科修复**：
1. Tab 切换改用固定外框 + `160ms` 指示条滑动 + 内容区即时/轻微 `120ms` 淡入，移除全屏点击锁。
2. 弹窗与 Popover 采用 `200–280ms` 无回弹减速入场、`160ms` 快速退出，基于锚点边缘定位（`top-start` / `bottom-start`）且支持随时反向打断。
3. 加上 `@media (prefers-reduced-motion: reduce)` 退化。

## 反例 4：把破坏性操作紧贴主操作且无防护

**坏表现**：
- 表单底部并排两个一样大的按钮：左边蓝色实心 `提交保存`，右边紧挨 4px 的红色实心 `清空全部数据`；点“清空”后没有任何确认或撤销，表单内容瞬间全灭。

**为什么不合格**：违反逆向费茨定律（防误触）与 Nielsen 容错原则（P0 数据丢失风险）。

**外科修复**：
1. 空间隔离：将 `清空` 降级为低视觉权重的 Ghost 文字按钮，放至表单另一侧或顶栏溢出菜单中，与主提交按钮拉开安全距离。
2. 容错闭环：点击清空后弹出明确二次确认（标题写清后果、按钮用明确动词 `清空内容` vs `保留`），或允许清空后 5 秒内一键“撤销恢复”。

## 反例 5：把手游 / PC 游戏 HUD 做成白底网页表单

**坏表现**：
- 暗黑奇幻 ARPG 游戏的背包与技能栏采用纯白圆角 Tailwind 卡片 + Inter 字体 + 灰色网页滚动条，战斗中纯细白字血量直接浮在雪地背景上完全看不清，且手柄方向键无法选中背包底部按钮。

**为什么不合格**：割裂世界观、动态背景不可读、违背 XAG 112/113 手柄焦点规范（P0/P1）。

**外科修复**：
1. 回归游戏本体材质与色彩语言（深曜石/羊皮纹理暗底、锻造金属细节边界与契合时代感的字体）。
2. 所有浮于 3D 镜头上的 HUD 数值加暗色柔和背板/外描边，保证雪地与暗洞双环境高对比可读。
3. 建立完整的上下左右方向键显式焦点图，增加清晰高光焦点框，并支持键鼠 ↔ 手柄键标实时热切换。
