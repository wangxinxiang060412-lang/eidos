# UI Visual Craft & Anti-AI-UI Checklist

- [ ] **审美气质契合产品**：已按产品定位选定合适视觉原型与配色极性，绝非套用千篇一律的“黑白极简”或“紫蓝渐变 SaaS 壳”。
- [ ] **60-30-10 色度纪律**：中性背景与表面占绝对主体，单屏仅 1 个明确主强调色，状态色严格用于表达真实状态。
- [ ] **反 AI 模板病（Anti-AI-UI）**：无未解释的胶囊汤、无卡片套卡片、无无意义紫蓝渐变与背景光斑、无滥用毛玻璃糊住正文、无装饰性 ✨ 图标或空洞营销大标题。
- [ ] **容器选型合理**：未把列表/表格/纯表单硬塞进多余卡片；卡片均具独立实体语义，无“重边框 + 重阴影”叠加，无多余分割线。
- [ ] **留白与接近性不等式**：严格满足 `元素内距 < 项间距 < 分组间距 < 区块间距`；卡片/弹窗四周留白均衡，无“头松脚挤”。
- [ ] **同心圆角与光学对齐**：嵌套圆角遵循 `外圆角 = 内圆角 + padding`；无 1–3px 近切边；文字距边缘 ≥ 12px；头像与评论正文字左边缘对齐；播放三角等不对称图形已光学居中；图标盒加 `flex-shrink: 0` 不被挤扁。
- [ ] **字体与排版工艺**：全产品最多 2 套字体（等宽字仅用于代码/数据），字阶收敛统一，中英混排行高舒展（中文 1.6+），价格/计数/表格数字全部开启 `tabular-nums`，单位与数字不异常拆行。
- [ ] **图标一致性**：全项目单一图标家族、单一描边粗细与统一尺寸；≤14px 小图标使用实心；严禁用 Emoji 替代 UI 图标；无粗糙手画 SVG。
- [ ] **亮/暗双模式质感**：亮色用多层柔和阴影（绝非脏黑重影）；暗色靠更亮表面阶梯 + 细腻顶边微光表达层次，无半透明重叠（No Onion Skin）。
- [ ] **多端适配与安全区**：`390px` 窄屏与 `1440px` 宽屏均无横向溢出；动态适配状态栏、灵动岛、小程序胶囊、底部手势区与软键盘弹出；平板/桌面已重组信息而非等比放大手机版。
