# UI Visual Craft, Refinement & Anti-AI Checklist

- [ ] **配色确认门禁遵守**：存量项目已完成 11 维色彩审查；合理配色已保留，整体改色或改品牌主色已获得用户明确确认。
- [ ] **独立美术语言与产品契合**：视觉结构、密度、排版与材质契合本产品领域（非套用千篇一律极简模板或简单换皮）。
- [ ] **60-30-10 色度与暗黑光影**：中性表面占主体，单屏仅 1 个核心强调色；亮色用三层柔影或 1px 细边二选一；暗色靠表面提亮 + 顶边微光，无黑坨阴影与透明叠脏。
- [ ] **全栈 Anti-AI-Design（26 项排雷）**：无无故小椭圆/胶囊包裹普通文字、无卡片套卡片、无图标机械套彩色圆角方底盒、无无故紫蓝渐变与光斑、无重复 KPI 卡片墙、无机械全站雷同布局节奏。
- [ ] **图标系统（10 项审查）**：必要才用图标；全产品单一家族、统一线宽/端帽/填充语法；≤14px 用实心；重心校准（如播放三角右偏）；禁 Emoji 充当 UI 图标；`flex-shrink: 0` 防挤压。
- [ ] **页面上下边界与安全区衔接**：顶栏、滚动内容、底栏与系统安全区协调统一（按场景选自然流 / 1px 硬边 / 滚动显现 / 平台材质）；滚到底部不被底栏挡住；软键盘弹出不夹死输入区。
- [ ] **数据展示美学（若含数据）**：按数据目的精准选型（数字/指标条/表格/趋势线/Sparkline）；柱状图零基线不扭曲比例；强制 `tabular-nums` 且单位不异常折行；高数据墨水比。
- [ ] **20 项高影响力精修核查**：字重层级清晰、基线与阅读左轴线对齐、同心圆角（$R_{\text{out}} = R_{\text{in}} + \text{pad}$）、留白不等式成立、零 1–3px 近切边、四周留白均衡、图片裁切合理无变形。
- [ ] **多端重组适配**：`390px` 窄屏与 `1440px` 宽屏无横向溢出，平板/桌面按空间重组信息而非机械放大手机版。
