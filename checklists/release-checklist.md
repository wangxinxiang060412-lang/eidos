# Final Release Gate Checklist (Ship / No-Ship)

发布或交付前的最终门禁——**任意一条 P0 红线门禁未通过，禁止签发通过结论。**

---

## 一票否决门禁（P0 Hard Gates）
- [ ] **零 P0 缺陷**：核心流程畅通无阻塞、零空壳假按钮、零数据丢失/误删无保护、零运行时崩溃、零严重对比度不可读或安全区遮挡死角。
- [ ] **权限与零回归门禁**：未擅自修改未获确认的品牌配色、整体色彩系统、品牌 Slogan 或法务文案；存量项目所有既有核心功能、接口与用户数据零回归。
- [ ] **诚实门禁**：程序状态与提示文案 100% 一致，绝不虚构成功反馈；严禁把未运行或未亲眼核查的画面/动效标为已验收。

## 综合体验与工艺门禁（P1–P2 Gates）
- [ ] **14 步运行验收完成**：已真实运行并检查全局 + 局部截图、宽/窄视口、深色模式、真实点击、返回保态、弹窗起止、滚动、数据准确度、上下边界与异常态。
- [ ] **Content Audit 通过**：已扫描全部 19 类可见文案，无 AI 鸡汤套话与冗余副标题，按钮语义明确，术语跨页一致。
- [ ] **动效连续性过关**：关键转场/弹层/折叠经运行观察或录屏/抽帧确认顺滑、锚点正确、可打断且兼容 `prefers-reduced-motion`。
- [ ] **全栈 Anti-AI 与 20 项精修过关**：无模板化 AI 视觉/图标/数据/动效痕迹；高影响力细节已精修。
- [ ] **前后对比确认正向收益**：已比对修改前后画面（若为存量优化），无收益或体验下降的改动已主动撤销回退。
- [ ] **性能与工程门禁全绿**：Web 关注 LCP ≤2.5s / INP ≤200ms / CLS ≤0.1；原生/游戏流畅不掉帧；typecheck / lint / 测试 / 构建零新增报错，Console 干净。

## 交付透明度门禁
- [ ] 已按 [delivery-report.md](../templates/delivery-report.md) 清晰汇报：验证证据、配色权限状态、前后对比与回退记录，以及 **`Not Checked`（受限未测项与复测方法）**。
