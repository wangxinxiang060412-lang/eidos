# Final Release Gate Checklist (Ship / No-Ship)

发布或交付前的最终门禁——**任意一条红色门禁（P0）未通过，禁止签发发布通过结论。**

---

## 一票否决门禁（P0 Hard Gates）
- [ ] **零 P0 缺陷**：核心流程畅通无阻塞、无空壳假按钮、无数据丢失/误删无保护、无运行时崩溃、无严重对比度不可读或系统安全区遮挡死角。
- [ ] **零功能回归**（存量项目）：所有既有核心功能、接口契约与状态数据验证完好。
- [ ] **无虚假验收声明**：严禁把未运行或未亲眼核查的画面、动效或真机表现标记为“已验收通过”。

## 质量与体验综合门禁（P1–P2 Gates）
- [ ] **主路径 P1 已清零**：空态、加载、报错重试、表单校验、防重提交、返回保态与关键键盘/读屏无障碍已落实。
- [ ] **多端真实画面已核查**：已查看桌面宽屏、移动窄屏（`390px`）与深色模式（若支持）的实际运行截图，并确认修复了“所见→所改”表中的所有明显缺陷。
- [ ] **动效已核查连续性**：关键转场/弹层/状态变化已通过运行观察或录屏/抽帧确认流畅、可打断、不切字、不跳变，且尊重 `prefers-reduced-motion`。
- [ ] **反 AI 模板病过关**：无无故紫蓝渐变、胶囊汤、嵌套卡片或模板化营销口号；文案精准自然。
- [ ] **性能符合平台基准**：Web 关注 LCP ≤ 2.5s / INP ≤ 200ms / CLS ≤ 0.1；原生/游戏滚动与交互流畅无明显掉帧，大列表已做懒加载或虚拟化。
- [ ] **工程构建全绿**：类型检查、Lint、测试与构建无新增报错，Console 干净。

## 交付透明度门禁
- [ ] 已使用 [delivery-report.md](../templates/delivery-report.md) 清晰列出：验证过的环境与视图、修复记录、以及 **`Not Checked`（因环境限制尚未验证的清单与复测方法）**。
