# Functional Completeness & Engineering Checklist

- [ ] **零空壳控件**：已逐一排查所有可见按钮、链接、Tab、开关、筛选、排序、分页与菜单，100% 绑定真实功能逻辑（无 `onClick={() => {}}`、无死链 `href="#"`、无假成功提示）。
- [ ] **核心任务端到端打通**：从操作入口到结果生效、数据读写与持久化（API/DB/本地存储）可完整走通，刷新/重进后状态符合预期。
- [ ] **受限能力诚实声明**：若因缺少后端接口/外部密钥/原生权限导致某能力无法完全实装，界面与交付报告均明确告知边界，未伪造成功结果。
- [ ] **关键按钮状态齐全**：按职责实现 Default / Hover / Active / Focus / Selected / Disabled / Loading（锁宽防抖动、防重复提交）。
- [ ] **适用异常态完整覆盖**：
  - [ ] 空数据态（清晰说明 + 行动入口）
  - [ ] 加载态（匹配布局骨架屏或进度指示，不锁死无关操作）
  - [ ] 失败/断网/超时态（人话原因 + 保留数据 + 重试按钮）
  - [ ] 表单校验（贴近字段提示、聚焦首错、失败不清空表单）
  - [ ] 取消离开拦截（未保存内容防误丢）
  - [ ] 搜索无结果 & 404/已删除兜底
  - [ ] 极端数据量（0 条、1 条、超长字符、大列表）表现稳健
- [ ] **存量零回归（若是存量项目）**：原有业务功能、路由参数、接口契约、状态管理与既有用户数据均未受损，改动范围严格收敛。
- [ ] **技术栈克制与代码清洁**：复用项目原有框架与依赖，无多余第三方库膨胀；事件监听、定时器、异步请求（`AbortController`）均在卸载时正确清理。
- [ ] **编译与运行零新增报错**：typecheck、lint、单元测试与生产构建全部通过，运行控制台无新增 Error 或未捕获异常。
