# UX & Information Architecture Checklist

- [ ] **首屏 1 秒清晰度**：用户打开页面无需解释即可明白产品用途、当前页面职责与唯一主操作。
- [ ] **核心任务步数合理**：高频核心任务 1–3 步可达，无多余中转页；复杂专业流程有清晰面包屑或层级反馈。
- [ ] **符合用户习惯（Jakob's Law）**：导航位、返回、搜索、关闭、快捷键与目标平台主流惯例一致，不强迫学习奇怪交互。
- [ ] **热区与防误触（Fitts's Law）**：高频主操作处于自然舒适触达区；删除/清空/支付等高损操作视觉克制且远离高频按钮；移动端热区 ≥ 44pt (iOS/小程序) / 48dp (Android)。
- [ ] **单屏聚焦（Hick's Law & Cognitive Load）**：每屏最多 1 个 Primary 按钮；顶层导航 ≤ 5 项；复杂配置已做渐进披露或智能默认值。
- [ ] **明确的可供性与示能**：可点击元素一眼可辨；非交互装饰/标签不伪装成按钮；孤立难懂图标已配文字或 Tooltip。
- [ ] **导航与返回健壮**：详情返回列表后保留滚动位置、筛选与搜索词；无循环跳转、死胡同或重复入口；系统手势返回与应用内返回一致；深层链接无历史栈时有合理回退页。
- [ ] **容错与撤销闭环**：轻度删除/归档支持即时生效 + 撤销 Toast；不可逆高损操作写明具体后果与明确动词按钮；表单有未保存内容时离开前提示确认。
- [ ] **界面文案自然精准**：按钮使用“动词 + 对象”，全产品术语统一，报错说清原因/数据安全/下一步操作，无机械 AI 营销口号与技术黑话。
