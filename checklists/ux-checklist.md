# UX, Information Architecture & Content Audit Checklist

- [ ] **功能表达 6 问通过**：打开页面 3 秒内清楚产品用途、本页职责、核心信息、可做操作、下一步与预期结果，不靠长篇说明文字硬撑。
- [ ] **核心任务步数合理**：高频任务 1–3 步可达，无多余中转页；复杂专业流程提供清晰面包屑或层级位置反馈。
- [ ] **符合用户习惯（Jakob's Law）**：导航位、返回、搜索、关闭、快捷键与目标平台/领域（含 B 端、分析平台、智能终端）主流惯例一致。
- [ ] **热区与防误触（Fitts's Law）**：高频主操作舒适易达；高危删除/清空远离主按钮；移动端热区 ≥44pt (iOS/小程序) / 48dp (Android)，车载 ≥60px。
- [ ] **单屏聚焦（Hick's Law & Cognitive Load）**：每屏最多 1 个 Primary 按钮；顶层导航 ≤5 项；复杂配置已做渐进披露或智能默认值。
- [ ] **明确的可供性与示能**：可点击元素一眼可辨；非交互胶囊/说明文字不伪装成按钮；难懂图标配文字或 Tooltip。
- [ ] **导航、返回与边界健壮**：详情返回列表保留滚动位、筛选与搜索词；无死胡同或重复入口；深层链接无历史栈有合理回退页；底栏不遮挡最后一条内容。
- [ ] **容错与撤销闭环**：轻度删除/归档支持即时生效 + 撤销 Toast；不可逆操作写明精确后果；表单未保存离开前拦截提示。
- [ ] **Content Audit（去 AI 化文案审计）**：
  - [ ] 已扫描全部 19 类可见文本（含二级页、弹窗、报错、空态与 `aria-label`），无 14 类模板化 AI 鸡汤与无价值解释性副标题。
  - [ ] 按钮均为明确“动词 + 对象”（无脱离上下文的“开始探索 / 立即体验 / 确定”），跨页面功能术语绝对一致。
  - [ ] 报错与反馈文案 100% 匹配程序真实状态（绝不虚构“已保存/已同步”），未擅改品牌 Slogan 与法务条款。
  - [ ] 文案长度与布局协同良好，未靠无限缩小字号迁就冗长文字。
