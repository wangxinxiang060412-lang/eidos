# Motion, Spatial Causality & Choreography Checklist

- [ ] **动效皆具空间因果**：所有菜单、日期选择器、弹窗、Sheet、卡片展开、折叠与页面过渡均有清晰触发来源、运动轨迹与合理退出，**零凭空闪现、零无反馈突兀消失**。
- [ ] **10 要素规格完整**：关键交互已明确触发源、按压初态、精确 `transform-origin`、物理过程、终点、稳定态、快速退场、中断反转、连点处理与减少动效降级。
- [ ] **非模板化差异选型**：根据组件空间关系选型（并非所有弹窗都从按钮缩放，并非所有页面都强用共享元素），**绝不全项目套同一时长或每页机械淡入上浮**。
- [ ] **生产响应速度达标**：直接反馈 `0–120ms`，效果态 `140–220ms`，空间转场 `180–340ms`，退出比进入快 20–30%；绝不把慢速演示动画塞进日常高频操作。
- [ ] **Spatial 与 Effects 分离**：颜色/透明度/阴影变化采用零回弹曲线；仅在合适空间转场或极小强调图标使用克制弹簧，大容器与正文绝不乱弹跳。
- [ ] **可打断与快速连点安全**：动画期间不锁死用户输入；中途反向操作从当前物理位置自然逆转；快速连点不卡死、不叠出双层浮层。
- [ ] **Stageshow 6 条生产工艺核查**：静框衬动、按钮改态原位锁宽过渡、展开折叠不硬切文字、打开弹层锚点不漂移、实体不幽灵半透、落位帧零 1px 跳变与字形闪烁。
- [ ] **交错克制与性能安全**：分阶段交错总跨度 ≤220ms；仅动画 `transform` / `opacity` / `clip-path`；尊重 `prefers-reduced-motion`（关闭位移缩放，保留 ≤120ms 清晰状态切换）。
