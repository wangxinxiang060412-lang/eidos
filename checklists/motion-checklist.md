# Motion & Interaction Continuity Checklist

- [ ] **动效皆有明确目的**：每个动画都在表达空间来源、状态因果、层级关系或进度反馈；无纯装饰性旋转、抖动或持续呼吸脉冲。
- [ ] **生产速度预算达标**：直接点击/按压反馈 0–120ms，局部状态 120–220ms，空间转场 220–360ms，退出比进入快 20–30%；绝不把 0.8–1.0s 的演示型慢动画塞进日常高频操作。
- [ ] **空间因果与静框衬动**：弹层从锚点展开、Sheet 从底边升起、退出回到原处；外框与固定导航保持稳定，仅让变化内容移动。
- [ ] **Spatial 与 Effects 曲线分离**：颜色/透明度/阴影变化采用零回弹曲线；仅允许在恰当的空间转场或极小强调图标中使用克制弹簧，大容器与正文绝不乱弹跳。
- [ ] **随时可打断与连点安全**：动画播放中不锁定用户输入；中途反向操作或快速连点从当前物理位置自然过渡，不跳回第 0 帧、不卡死、不重叠。
- [ ] **微观连续性（无低级动效 Bug）**：
  - [ ] 展开/折叠容器时边缘不硬切正在显示的文字。
  - [ ] 按钮文案/Loading 切换在原节点平滑完成且锁定最小宽，不引起邻居跳动。
  - [ ] 列表变高/筛选时，已打开的 Popover / 下拉菜单锚点不漂移。
  - [ ] 面板打开时内容已就位，无空壳白框停顿。
  - [ ] 动画结束落位帧零 1px 跳变与字形闪烁。
- [ ] **交错克制与性能安全**：列表交错总跨度 ≤ 250ms；仅对 `transform` / `opacity` 等合成属性做动画；离屏/后台自动停止无效动画。
- [ ] **尊重减少动态效果**：开启 `prefers-reduced-motion: reduce` 或系统减少动效开关时，关闭位移/缩放/视差，保留 ≤120ms 清晰状态切换且不丢失任何反馈。
