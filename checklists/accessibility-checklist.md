# Accessibility & Inclusive Design Checklist (WCAG 2.2 AA+)

- [ ] **文本对比度（SC 1.4.3）**：所有常规正文与次要可读文案在亮/暗模式及材质背景上对比度 **≥ 4.5:1**；大号标题（≥24px 或 ≥18.66px 粗体）**≥ 3:1**。
- [ ] **非文本与控件对比度（SC 1.4.11）**：输入框边框、复选框、开关轨道、状态图标、图表数据与焦点环对比度 **≥ 3:1**。
- [ ] **不单靠颜色传递信息（SC 1.4.1）**：成功/失败/警告/选中/涨跌/游戏敌我状态同时具备图标、文字、下划线或形状差异，色盲用户清晰可辨。
- [ ] **触控与目标尺寸（SC 2.5.8 & 平台 HIG）**：Web 交互目标 ≥ 24×24px（移动端 Web ≥ 44px），iOS/小程序 ≥ 44×44pt，Android ≥ 48×48dp，相邻目标间距 ≥ 8px。
- [ ] **键盘全流程可达（Web / Desktop）**：仅用 `Tab` / `Shift+Tab` / `Enter` / `Space` / `Esc` / 方向键即可走完所有核心任务；Tab 顺序符合视觉阅读顺序。
- [ ] **焦点清晰且不被遮挡（SC 2.4.7 & 2.4.11）**：所有可聚焦控件具备清晰的 `:focus-visible` 轮廓（≥2px，≥3:1 对比度）；聚焦时不会被吸顶头、底栏或浮层完全挡住；Modal/Drawer 正确锁焦并在关闭时归还焦点至触发器。
- [ ] **原生语义与读屏器（VoiceOver / TalkBack）**：使用正确语义标签（`<button>`, `<a>`, `<main>`, `<nav>`, 连续标题层级）；纯图标按钮有准确操作型 `aria-label`；装饰图标设 `aria-hidden="true"`；异步提示接 `aria-live`。
- [ ] **字体放大与重排（SC 1.4.4 / Dynamic Type）**：文字放大至 200% 或开启系统大字号时无文字重叠、无核心操作裁切、无异常横向滚动。
- [ ] **运动与光敏安全**：完整响应 `prefers-reduced-motion`；全界面无 >3 次/秒的高频闪烁元素。
- [ ] **游戏与手柄专项（若适用，XAG 103/112/113）**：完整方向键焦点图无死角；键鼠/手柄键标实时热切换；关键战斗反馈具备视觉+音效+震动冗余提示；字幕带可读暗底背景与字号调节。
